# Causal-information v2 sparse Kraus candidate

This profile adds an explicit finite-cutoff dynamics to the v1 kinematics. A
history basis ray is indexed by an unlabeled finite causal set. Each allowed
growth move adds one maximal element above a down-set precursor. Automorphism
orbits, rather than natural labels, define physical branches.

The aggregate branch probability is proportional to the exact orbit
multiplicity times rational fugacities for the link-count increment,
diamond-count increment, and precursor size. Rank-one matrix-unit Kraus
operators make complete positivity and trace preservation exact at each
implemented source.

The profile is deliberately modest: it is diagonal in the recorded branch
outcomes, has no proven quantum Bell-causality law, and has no extension theorem
for infinite covariant events. It is therefore a dynamics candidate, not a
completed quantum sequential-growth theory.
