# Operator QSG research candidate

This profile implements exact checks of selected TOBC, NTOBC, and CPOBC
relations from arXiv:2603.25503v1 and a bounded rational-matrix search in
dimensions three and four. Search survivors satisfy only a declared core
relation set; no survivor receives a representation certificate until every
transition, covariance, normalization, Bell-causality, and invertibility
condition is checked.
