# Quantum Causal Information Model v1

v1は、固定した有限グラフ上の量子運動学を曖昧さなく定義し、グラフ自体を量子化する
部分が未完成であることを明示する。

固定セクターは有限有向非巡回グラフ `G` である。各辺に有限次元Hilbert空間、各頂点に
入辺のテンソル積から出辺のテンソル積へのCPTP写像を割り当てる。入力境界状態と
頂点写像をトポロジカル順序で合成すると、出力境界までのCPTP写像が一意に得られる。
グラフの到達可能性が因果半順序 `C` を定める。

この有限セクターについては、状態、チャネル、境界観測量、ラベル同値性が定義済みで
ある。未定義なのは次である。

- 異なるグラフとHilbert次元を足し上げる測度
- Lorentzian振幅の正規化、収束、確率解釈
- カットオフ除去と粗視化写像
- 3+1次元相を選ぶ力学
- 候補から導かれる計量応答または二点関数

したがってv1の許可判定は `KINEMATICS_DEFINED` までである。有限量子回路がCPTPで
あることは `DYNAMICS_DEFINED` や `BACKGROUND_INDEPENDENCE_PASS` を意味しない。

作用仮説は最大4個の演算子

```text
S_theta[G,E,rho] = sum_i theta_i O_i[G,E,rho]
```

に制限する。既知のEinstein作用、目標次元、Spin-2射影子を演算子基底へ直接入れる
ことは禁止する。
