# Final-Theory Program Charter

## 目的

Final-Theory Programは、背景独立な微視的量子模型を生成し、できるだけ早く反証する
ための本流である。目標は既存理論の用語を統合することではなく、同一の微視的定義
から次の鎖を閉じることである。

```text
時空を入力しない量子模型
  -> 安定した3+1次元ローレンツ相
  -> 質量ゼロ・2偏極のSpin-2極
  -> 保存されたT_{mu nu}への普遍結合
  -> Einstein自己相互作用
  -> ブラックホール、物質、宇宙論、予言
```

## 証拠規則

1. 定義、解析導出、数値支持、ヒューリスティック、予想を別フィールドに保存する。
2. 陽性対照oracleの結果を候補模型の証拠として流用しない。
3. 学習、検証、保留因果構造を分離し、保留集合で係数を再調整しない。
4. 生の基底、ゲージ、ラベルに依存する一致ではなく、不変量または明示的写像を要求する。
5. 二点関数の極だけでなく、Ward恒等式、物理偏極、残差の符号、普遍結合を別々に判定する。
6. Spin-2 Gate通過後にのみ三点頂点をEinstein-Hilbert頂点と比較する。
7. 失敗を隠さず、kill conditionが成立した候補を `CANDIDATE_REJECTED` として保存する。

## 現在の中心候補

`causal_information_v1` は有限因果順序、有限次元Hilbert空間、CPTP写像、整合する
有限状態からなるカットオフ運動学を定義する。現時点で、全因果構造上の測度、
振幅の収束、3+1次元相、候補から導いた二点関数は存在しない。このため
`KINEMATICS_DEFINED` は許可するが、`DYNAMICS_DEFINED` と
`BACKGROUND_INDEPENDENCE_PASS` は許可しない。

## 他系統の役割

- `causal_set_amplitude_family`: 因果順序の状態和と連続相に関する比較候補
- `quantum_channel_network_family`: 情報流から幾何を復元する比較候補
- String-Compiler: 成功候補と既知の弦理論整合性の衝突検査
- QG-Bench: 固定背景上の既知連続結果を回収できるかの検算

## v0.1停止条件

v0.1は次が揃った時点で凍結する。

- ゲートと候補台帳が機械検証可能
- 中心候補の有限カットオフ運動学が明記済み
- 既知Spin-2運動学の独立陽性対照が実行可能
- 候補由来の応答がない場合に陽性対照を誤転用せず `SPIN2_NOT_FOUND` と判定
- 結果JSONが `FINAL_THEORY_OPEN` を保持

次版の開始条件は、候補自身から計算可能な粗視化二点応答または、その構成を
不可能とする明確な反証結果である。
