# Continuum-phase benchmark

Candidate and random-control ensembles are compared without retuning at sizes
three, four, and five. Order fraction, interval abundances, height, width,
automorphism entropy, susceptibility, and a Binder-like order-fraction
cumulant are recorded.

Dimension, correlation length, and continuum exponents are left undefined
because the exact domain cannot support them. The resulting status is
`CONTINUUM_PHASE_RESOURCE_BLOCKED`.
