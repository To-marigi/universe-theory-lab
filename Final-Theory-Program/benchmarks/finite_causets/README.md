# Exact finite-causet benchmark

Production enumeration grows maximal elements above every down-set, then
canonicalizes by exhaustive permutations. It is complete through `n=5`, where
the unlabeled counts are `1, 1, 2, 5, 16, 63`. An independent forward-relation
mask oracle agrees as exact sets through `n=4`.

The domain limit is explicit. No `n>5` completeness claim is made.
