# Quantum-measure benchmark

For the sparse Kraus profile, each branch is a rank-one matrix unit with an
exact rational radicand. Instrument completeness, non-negative probabilities,
and diagonal decoherence-functional strong positivity are exact through
`n=5`.

The infinite covariant-event extension and quantum Bell causality remain open,
so the benchmark returns `COVARIANT_MEASURE_PARTIAL`.
