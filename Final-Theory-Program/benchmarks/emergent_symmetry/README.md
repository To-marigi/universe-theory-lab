# Emergent-symmetry pre-gate

This gate precedes every spin claim. It requires stable dimension, decreasing
isotropy violation, stable long-wavelength dispersion, a coarse-graining flow,
and held-out replication. None is currently defined for the candidate.

The gate therefore returns `SPIN_CLASSIFICATION_NOT_YET_DEFINED` and
`SPIN2_GATE_BLOCKED_BY_CONTINUUM`.
