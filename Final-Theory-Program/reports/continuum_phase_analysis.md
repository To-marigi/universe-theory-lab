# Continuum-phase analysis

A continuum candidate would require, at minimum:

1. three or more substantially separated sizes;
2. stable independent dimension estimates;
3. a correlation length that grows relative to the discreteness scale;
4. finite-size scaling compatible across frozen couplings;
5. separation from random/layered controls;
6. held-out replication.

The current exact sizes `3,4,5` satisfy only the literal count of three sizes,
not the scale separation or observable validity requirements. No certified
large-ensemble candidate sampler exists.

Status:

```text
CONTINUUM_PHASE_RESOURCE_BLOCKED
```

This is distinct from `CONTINUUM_PHASE_NOT_FOUND`: the current calculation is
not strong enough to exclude a continuum phase.
