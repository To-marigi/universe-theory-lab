\begin{abstract}
We report a fail-closed reproducibility framework for finite quantum
sequential-growth calculations.  The framework separates candidate evidence
from controls, binds claims to versioned machine-readable artifacts, requires
independent replay before promotion, and records wall-time, memory, disk, and
exact-enumeration limits as open resource boundaries.  Existing bounded
artifacts include a 5-seed, 1,024-trajectory-per-seed small-$n$ regression; 40
deterministic fixture trajectories over two sampler profiles; eight
four-dimensional Minkowski-control fixtures; and five synthetic supervisor
modes.  These are implementation checks, not production measurements.  In a
separate exact random-growth scaling review, primary and independent paths
complete growth through cardinality 38 with identical trajectory and relation
digests.  The last fully enumerated source, $n=37$, has 3,791 down-sets; an
attempted step from source size $n=38$ detects at least 4,097 down-sets and
fails closed at the declared cap of 4,096.  This is a resource-limit
observation, not an impossibility theorem.  The active candidate uses a
nonlocal link/diamond/precursor weight for which no exact reduced-state
factorisation is certified, so no candidate production evidence is reported.
The result is a reproducible methods record with explicit nonclaims, not a
physical verdict on the candidate model.
\end{abstract}

\section{Background and objective}

Sequential-growth models construct a causal set one element at a time.  The
classical framework combines covariance and a Bell-causality condition with a
stochastic growth law\cite{RideoutSorkin2000}; complex and quantum variants
introduce additional extension, consistency, or operator questions
\cite{SuryaZalel2020,Gudder2012,SrivastavaSurya2026}.  Numerical causal-set
studies also make clear that finite-size evidence and continuum claims require
different controls\cite{GlaserOConnorSurya2018}.  The present work does not
propose a new physical dynamics.  Its objective is narrower: to make the
authorization boundary around finite computations explicit and reproducible.

The contribution is a concrete workflow with four linked parts:

\begin{enumerate}
  \item exact arithmetic and deterministic ticket generation for bounded
        sampler fixtures;
  \item independent implementations that replay the same frozen wire format;
  \item external resource supervision with atomic, digest-checked promotion;
  \item a verdict grammar that prevents finite tests and resource exhaustion
        from being promoted to physical or mathematical no-go claims.
\end{enumerate}

All numerical counts reported below are read from committed result artifacts.
No new candidate trajectory or solver calculation is introduced by manuscript
assembly.

\section{Scope and threat model}

Finite exact calculations can produce convincing numerical output while still
leaving the semantic scope, sampling measure, replay independence, and
resource boundary underspecified.  The purpose of this work is to make those
conditions machine-auditable before any candidate result is promoted.

The project contains two different layers.  The first is an earlier mathematical
paper on statewise versus operator semantics at dimension two\cite{Osaki2026PaperI}.
The present manuscript is a separate, scoped methods record.  It preserves the
published Paper I record and does not revise its claims.  The second layer is
the control and production protocol for larger finite-growth measurements.  We
close that layer for manuscript assembly at the bounded evidence boundary
described below.

The global project verdict remains \code{FINAL\_THEORY\_OPEN}.  In particular,
we do not claim a complete finite occurrence-ON semantics lattice, a resolution of the
full 955 or 721 profiles, candidate physical validity, a continuum limit,
production spectral dimension, or a solver impossibility result.

The workflow is designed against four recurrent failure modes.  First, a
bounded fixture can be described as though it were a production sample.
Second, two nominally independent checks can silently share the same
implementation.  Third, a timeout or enumeration cap can be rewritten as a
negative theorem.  Fourth, a valid temporary output can be promoted even
though its certificate, source identity, or process cleanup failed.  Each
failure mode is represented by a machine-readable authorization field or a
supervisor fixture below.

\section{Machine-readable authorization model}

Every stage has a versioned JSON result, a semantic SHA-256 digest, a report,
and an explicit authorization boundary.  A preflight may validate code paths
and fixtures without authorizing production trajectories.  The following
invariants are required for the scoped manuscript:

\begin{enumerate}
  \item bounded fixtures are labelled non-evidentiary;
  \item primary and independent implementations agree before promotion;
  \item candidate and control paths have separate identities and budgets;
  \item approximate fallbacks are disabled unless a separate bias and mixing
        certificate exists;
  \item a timeout, memory limit, or exact enumeration cap yields
        \code{RESOURCE\_LIMIT\_OPEN}, never a scientific negative result;
  \item the published Paper I record is immutable and any later publication
        uses a new versioned archive.
\end{enumerate}

The Phase-C artifact certifies the claim-boundary ledger, verdict grammar,
frozen-artifact invariance, and preflight/budget separation.  It adds no
scientific verdict and keeps the solver gate closed.

\section{Bounded exact controls}

\subsection{Finite sampler fixtures}

Two distinct preflights are retained.  A small-$n$ sampler regression follows
five fixed seeds, with 1,024 trajectories per seed, through cardinality three.
Branch selection uses integer tickets over exact rational weights.  The five
terminal distributions pass their declared diagnostic comparison with the
exact distribution.  This comparison is a regression test; its six-sigma
window is not a scientific acceptance threshold.

A later deterministic replay preflight checks two labelled implementation
profiles, two seeds, two trajectory indices, and target sizes $1$ through $5$,
giving 40 fixture trajectories.  The finite catalogue reproduces the exact
unlabelled level counts
\[
  1,\;1,\;2,\;5,\;16,\;63
\]
through cardinality five.  Primary and independent relation and trajectory
digests agree, a repeated primary fixture is deterministic, and both paths fail
closed at their exact down-set caps.  The presence of a candidate-labelled
fixture validates only the frozen code path and identity boundary.  It is not
candidate evidence and does not authorize candidate sampling.

\subsection{Four-dimensional positive control}

The Minkowski control constructs fixed-cardinality Alexandrov-interval
relations at bounded sizes $1$, $4$, $8$, and $13$.  Eight primary/replay
fixtures agree on relation digests, preserve cardinality, and pass the declared
four-dimensional anchor check.  This is an implementation preflight.  The
observable pipeline, production seed set, and independent observable digest
are not promoted by this manuscript.

The positive control is deliberately separated from the BDG action proposal.
No BDG coefficient fit, nonlocal scale fit, action-weighted ensemble, or
candidate-derived calibration is performed.

\subsection{Bounded cost observations}

A three-case cost preflight completes one $N=27$ random-growth fixture and one
$N=27$ Minkowski fixture.  The planned $N=60$ random-growth case returns
\code{RESOURCE\_LIMIT\_OPEN} at the exact down-set cap of 4,096 after a bounded
attempt.  No cap increase or approximate fallback is applied.  Wall times are
environment-specific observations and are therefore kept in the machine
artifact rather than treated as portable performance claims.

\section{Independent replay and runtime safety}

The replay contract fixes the ticket wire format, branch ordering, relation
digest, and trajectory digest.  The runtime layer rejects oversized tickets,
excessive rejection attempts, exact down-set cap violations, and cyclic height
dynamic programs.  Hard-supervisor fixtures exercise wall-time limits,
process-tree termination, memory and disk caps, invalid-digest rejection,
atomic promotion, retry prohibition, and failed-artifact non-promotion.

The supervisor test matrix has five modes: success, invalid certificate,
process-tree timeout, memory limit, and disk limit.  Only the successful,
digest-valid fixture is promoted.  Every failed or resource-limited fixture is
left unpromoted, each process tree is reaped, and no automatic retry occurs.

These checks establish the declared runtime contracts.  They do not imply that
the production sampler has been connected to the supervisor or that a
production trajectory has been generated.  The scoped closure records zero new
control trajectories, zero candidate trajectories, and zero solver calls.

\section{Exact scaling boundary}

For the uniform random-growth control, every branch has weight one.  The
proposed exact route is an ideal-count recurrence over a maximal vertex $v$:
\[
 I(S)=I(S\setminus\{v\})+
 I\bigl(S\setminus(\{v\}\cup\operatorname{Pred}_S(v))\bigr),
 \qquad I(\varnothing)=1.
\]
This recurrence is recorded as a design only; it is not implemented in the
present closure.

The preceding exact scaling review uses the existing enumerating route under a
cap of 4,096 down-sets.  Both implementations complete 38 successful growth
steps and produce the same cardinality-38 relation and trajectory digest.  The
last source for which all down-sets are enumerated is $n=37$, with exact count
3,791.  When the cardinality-38 relation is used as the next source, both
implementations detect a lower bound of 4,097 down-sets and stop before drawing
the next transition.  Thus the recorded boundary is an attempted step
\emph{from} source size $n=38$, not a failure to construct the size-38 relation.

This boundary supports the statement that the current exact enumerating path
does not reach the planned $N=60$ production scale under its declared cap.  It
does not support any of the following stronger statements: that no algorithm
can scale, that the control has a physical continuum limit, or that a candidate
is ruled out.

\section{Candidate exclusion boundary}

The active candidate profile is
\code{causal\_information\_v2\_sparse\_kraus}.  Its frozen weight has the
form
\[
 w(P)=\left(\frac{2}{3}\right)^{\Delta\mathrm{links}(P)}
       \left(\frac{3}{2}\right)^{\Delta\mathrm{diamonds}(P)}
       \left(\frac{4}{5}\right)^{|P|}.
\]
Unlike the uniform control, this is a nonlocal set function of the precursor.
The repository contains no certified finite reduced-state recurrence or
factorisation theorem that would permit exact weighted ticket selection without
enumerating the relevant states.  The uniform-control recurrence is therefore
not reused for the candidate.

Candidate access is excluded from the scoped manuscript.  This is a protocol
decision, not a candidate obstruction or a negative physical result.  The
bounded candidate-labelled regression fixtures described above do not change
this boundary: no candidate production observable, continuum estimate, or
acceptance threshold is formed.

\subsection{Reproduction protocol}

A clean reproduction has three levels.  First, verify the archived hashes and
the source-commit binding without executing research code.  Second, run the
focused Phase-B and Phase-C tests, followed by lint and static type checks.
Third, if a fresh PDF is required, build the TeX source in the digest-pinned,
network-disabled container recorded in the PDF build report.  Reproduction of
existing fixtures does not reopen candidate or production authorization.

The upload layout consists of one directly previewable PDF and one deterministic
compressed supplement.  The PDF is not duplicated inside the supplement; the
supplement binds it by SHA-256.  Raw third-party papers, extracted reference
texts, credentials, caches, and unbounded solver outputs are excluded.

\section{Unresolved work and reopening rule}

The following remain outside the present paper: production spectral-window and
statistical freezes, N=60 control training/holdout, an executable BDG ensemble,
candidate weighted production sampling, and full 955/721 classification.  A
future reopening requires a new owner-approved scope, a versioned budget,
independent replay, and (for candidate access) a certified weighted-state
factorisation.  The existing Paper I Zenodo record must not be mutated.

\section{Conclusion}

The project now has a finite, auditable methods boundary.  Bounded controls,
replay, resource guards, and candidate exclusion are machine-recorded, while
the exact scaling stop is reported as a resource boundary rather than a
scientific no-go.  This supports a scoped control-and-methods manuscript.  It
does not close the physical theory question, which remains
\code{FINAL\_THEORY\_OPEN}.
