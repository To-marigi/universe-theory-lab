\begin{abstract}
We describe a fail-closed reproducibility framework for finite quantum
sequential-growth calculations.  The framework separates candidate evidence
from controls, binds claims to versioned machine-readable artifacts, requires
independent replay before promotion, and treats wall-time, memory, and exact
enumeration limits as explicit resource boundaries.  Within the bounded scope
reported here, exact sampler fixtures, fixed-ticket replay, a four-dimensional
Minkowski positive-control preflight, runtime guards, and hard-supervisor
fixtures pass their declared checks.  An exact random-growth scaling review
reproduces a down-set cap boundary at source size $n=38$: both primary and
independent paths reach $n=37$ with 3,791 down-sets and reject the next step
when the lower bound exceeds the cap of 4,096.  This is a resource-limit
observation, not an impossibility theorem.  The active candidate uses a
nonlocal link/diamond/precursor weight for which no exact reduced-state
factorisation is certified; it is therefore excluded from candidate evidence.
The result is a reproducible methods record with explicit nonclaims, not a
physical verdict on the candidate model.
\end{abstract}

\section{Scope and claim boundary}

Finite exact calculations can produce convincing numerical output while still
leaving the semantic scope, sampling measure, replay independence, and
resource boundary underspecified.  The purpose of this work is to make those
conditions machine-auditable before any candidate result is promoted.

The project contains two different layers.  The first is an earlier mathematical
paper on statewise versus operator semantics at dimension two\cite{Osaki2026PaperI}.
The present manuscript is a separate, scoped methods record.  It preserves the
published Paper I record and does not revise its claims.  The second layer is
the control and production protocol for larger finite-growth measurements.  We
close that layer for manuscript assembly at the bounded evidence boundary
described below.

The global project verdict remains \code{FINAL\_THEORY\_OPEN}.  In particular,
we do not claim a complete finite ON semantics lattice, a resolution of the
full 955 or 721 profiles, candidate physical validity, a continuum limit,
production spectral dimension, or a solver impossibility result.

\section{Machine-readable authorization model}

Every stage has a versioned JSON result, a semantic SHA-256 digest, a report,
and an explicit authorization boundary.  A preflight may validate code paths
and fixtures without authorizing production trajectories.  The following
invariants are required for the scoped manuscript:

\begin{enumerate}
  \item bounded fixtures are labelled non-evidentiary;
  \item primary and independent implementations agree before promotion;
  \item candidate and control paths have separate identities and budgets;
  \item approximate fallbacks are disabled unless a separate bias and mixing
        certificate exists;
  \item a timeout, memory limit, or exact enumeration cap yields
        \code{RESOURCE\_LIMIT\_OPEN}, never a scientific negative result;
  \item the published Paper I record is immutable and any later publication
        uses a new versioned archive.
\end{enumerate}

The Phase-C artifact certifies the claim-boundary ledger, verdict grammar,
frozen-artifact invariance, and preflight/budget separation.  It adds no
scientific verdict and keeps the solver gate closed.

\section{Bounded exact controls}

\subsection{Finite sampler fixtures}

The bounded sampler preflight checks two labelled profiles: the active candidate
identity and a uniform random-growth control.  It covers 40 deterministic
fixtures at sizes $1$ through $5$, with exact level counts
\[1,\;1,\;2,\;5.\]
Primary and independent replay digests agree, repeated primary fixtures are
deterministic, and both paths fail closed at their exact down-set caps.  These
fixtures validate implementation and provenance; they are not production
measurements and do not establish candidate physics.

\subsection{Four-dimensional positive control}

The Minkowski control constructs fixed-cardinality Alexandrov-interval
relations at bounded sizes $1$, $4$, $8$, and $13$.  Eight primary/replay
fixtures agree on relation digests, preserve cardinality, and pass the declared
four-dimensional anchor check.  This is an implementation preflight.  The
observable pipeline, production seed set, and independent observable digest
are not promoted by this manuscript.

The positive control is deliberately separated from the BDG action proposal.
No BDG coefficient fit, nonlocal scale fit, action-weighted ensemble, or
candidate-derived calibration is performed.

\section{Independent replay and runtime safety}

The replay contract fixes the ticket wire format, branch ordering, relation
digest, and trajectory digest.  The runtime layer rejects oversized tickets,
excessive rejection attempts, exact down-set cap violations, and cyclic height
dynamic programs.  Hard-supervisor fixtures exercise wall-time limits,
process-tree termination, memory and disk caps, invalid-digest rejection,
atomic promotion, retry prohibition, and failed-artifact non-promotion.

These checks establish the declared runtime contracts.  They do not imply that
the production sampler has been connected to the supervisor or that a
production trajectory has been generated.  The scoped closure records zero new
control trajectories, zero candidate trajectories, and zero solver calls.

\section{Exact scaling boundary}

For the uniform random-growth control, every branch has weight one.  The
proposed exact route is an ideal-count recurrence over a maximal vertex $v$:
\[
 I(S)=I(S\setminus\{v\})+
 I\bigl(S\setminus(\{v\}\cup\operatorname{Pred}_S(v))\bigr),
 \qquad I(\varnothing)=1.
\]
This recurrence is recorded as a design only; it is not implemented in the
present closure.

The preceding exact scaling review uses the existing enumerating route under a
cap of 4,096 down-sets.  The primary and independent paths agree through
source size $n=37$, where the exact count is 3,791.  At $n=38$ the count has a
lower bound of 4,097, so the cap is reached.  The same relation and trajectory
digests are obtained on both paths.

This boundary supports the statement that the current exact enumerating path
does not reach the planned $N=60$ production scale under its declared cap.  It
does not support any of the following stronger statements: that no algorithm
can scale, that the control has a physical continuum limit, or that a candidate
is ruled out.

\section{Candidate exclusion boundary}

The active candidate profile is
\code{causal\_information\_v2\_sparse\_kraus}.  Its frozen weight has the
form
\[
 w(P)=\left(\frac{2}{3}\right)^{\Delta\mathrm{links}(P)}
       \left(\frac{3}{2}\right)^{\Delta\mathrm{diamonds}(P)}
       \left(\frac{4}{5}\right)^{|P|}.
\]
Unlike the uniform control, this is a nonlocal set function of the precursor.
The repository contains no certified finite reduced-state recurrence or
factorisation theorem that would permit exact weighted ticket selection without
enumerating the relevant states.  The uniform-control recurrence is therefore
not reused for the candidate.

Candidate access is excluded from the scoped manuscript.  This is a protocol
decision, not a candidate obstruction or a negative physical result.

\section{Unresolved work and reopening rule}

The following remain outside the present paper: production spectral-window and
statistical freezes, N=60 control training/holdout, an executable BDG ensemble,
candidate weighted production sampling, and full 955/721 classification.  A
future reopening requires a new owner-approved scope, a versioned budget,
independent replay, and (for candidate access) a certified weighted-state
factorisation.  The existing Paper I Zenodo record must not be mutated.

\section{Conclusion}

The project now has a finite, auditable methods boundary.  Bounded controls,
replay, resource guards, and candidate exclusion are machine-recorded, while
the exact scaling limit is reported as a resource boundary rather than a
scientific no-go.  This supports a scoped control-and-methods manuscript.  It
does not close the physical theory question, which remains
\code{FINAL\_THEORY\_OPEN}.
