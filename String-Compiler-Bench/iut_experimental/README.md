# IUT experimental track

This directory contains a deliberately negative/guarded experiment.

It does **not** implement inter-universal Teichmüller theory, derive the ABC
conjecture, or assign IUT log-volumes to string backgrounds. It tests two
separate claims:

1. **H-IUT0 (software claim):** frame-tagged values cannot be compared without
   an explicit, directional morphism that records preserved and forgotten
   structure.
2. **IUT-native bridge (mathematical/physical claim):** a bridge is considered
   only after an explicit map from a physical background to valid initial
   Θ-data, model-independence, duality, non-redundancy, prediction, and evidence
   gates.

No physical-to-initial-Θ-data map is presently defined. The honest v0.1 result
is therefore:

- type discipline: `IUT_TYPE_SYSTEM_ONLY`
- native arithmetic/physics bridge: `IUT_NOT_APPLICABLE`

The published IUT papers and the Scholze–Stix objection are treated as distinct
sources. Disputed ABC/Szpiro consequences are never used as test oracles.
