## 選択: 明示的Wilson線を持つ一つの幾何学的部分軌道での独立root enumeration

最も情報利得が高い次実験は、四分岐を広く浅く追加することではなく、一次資料から
明示的な二本のWilson線ベクトルとNarain格子の基底を一組固定し、heterotic側だけで
未破れroot systemを列挙することです。

### 入力

- 規約を固定した `E8⊕E8` または `D16^+` 格子基底
- `T2` の複素構造・Kähler modulus
- 二本の明示的Wilson線
- duality chamberとvalidity domain

### 保留出力

- root lattice rank
- Cartan matrix
- discriminant group
- global gauge-group候補

### 合格条件

1. F-theory側のfiberから得るADE代数をheterotic実装へ入力しない。
2. `α·A_i ∈ Z` を満たすrootを全列挙してCartan成分を導く。
3. Wilson線の一つを消す二つのenhancement locusを保留する。
4. Wilson線成分を一つ削るmutationが検出される。
5. 同じroot systemが二つの独立基底で一致する。

この実験が通るまで、4D EFT loweringへ進みません。
