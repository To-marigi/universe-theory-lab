# Completion gap matrix

String-Compiler Benchの成功範囲と超弦理論全体の完成度を混同しないための表です。

| 項目 | 状態 | v0.1で確認する証拠 |
|---|---|---|
| perturbative definition | PARTIAL | 既知のstring field theory定式化はあるが全背景共通ではない |
| nonperturbative definition | OPEN | 本ベンチは与えない |
| background independence | OPEN | K3/T2という指定背景を用いる |
| duality unification | PARTIAL | 既知の8D双対性の型付きIRを検査 |
| vacuum classification | PARTIAL | Picard rank 16の指定4次元部分空間のみ |
| 4D EFT lowering | BLOCKED | v0.1停止条件により未実装 |
| moduli stabilisation | OPEN | flux potentialを扱わない |
| supersymmetry breaking | OPEN | 扱わない |
| de Sitter/cosmology | OPEN | 扱わない |
| Standard Model spectrum | OPEN | 扱わない |
| masses and couplings | OPEN | 8D保護データ検査のみ |
| vacuum selection | OPEN | 選択測度・選択則なし |
| unique observable prediction | OPEN | 新規観測予言なし |

結論は導けません。
