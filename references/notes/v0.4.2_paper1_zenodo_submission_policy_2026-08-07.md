# Paper I Zenodo submission-policy source note (2026-08-07)

## Source claims

Zenodo's official documentation, retrieved on 2026-08-07, distinguishes DOI
reservation from DOI registration.  Zenodo normally registers a DOI when a
record is published.  “Get a DOI now!” is an optional advance-reservation
action for a depositor who needs the DOI before publication.

The file-management documentation allows up to 100 files and recommends an
archive for 20 or more files.  It also supports choosing a previewable file as
the default record preview.  The description documentation recommends using
the main description as an abstract and allows separate methods, technical,
or other descriptions.  The publication-date field is required and defaults
to the draft-creation date.

Official URLs, versioned here by retrieval date:

- <https://help.zenodo.org/docs/deposit/describe-records/reserve-doi/>
- <https://help.zenodo.org/docs/deposit/manage-files/>
- <https://help.zenodo.org/docs/deposit/describe-records/descriptions/>
- <https://help.zenodo.org/docs/deposit/describe-records/publication-date/>
- <https://help.zenodo.org/docs/deposit/create-new-upload/>

## Project application

Paper I uses no advance DOI reservation.  The human depositor selects “No, I
need one” but does not click “Get a DOI now!”.  The local DOI remains null
until Zenodo registers it at publication.

The recommended upload is a standalone PDF plus one deterministic supplement
archive.  This preserves direct PDF preview without duplicating the PDF inside
the supplement; the supplement binds the external PDF by SHA-256.  The main
description is the public abstract.  The detailed claim boundary and AI
disclosure are separate additional descriptions.  The local publication date
remains null, while the required UI value must be checked against the actual
first-public date immediately before publication.

## Boundary

These service-documentation facts do not create or save a Zenodo draft,
reserve or assign a DOI, upload a file, publish a record, validate Paper I, or
authorize any release gate.  The pages are live HTML documentation; no local
copy is substituted for their exact URLs, and the retrieval date is part of
each bibliography record.
