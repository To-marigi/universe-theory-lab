# Paper I Zenodo deposit-workflow note (2026-08-06)

## Source claims

Zenodo's official documentation, retrieved on 2026-08-06, states that a new
upload can be saved as a draft, previewed, and published; the DOI is registered
only on publication unless one is reserved in advance.  The current page also
warns that record files can be changed by the depositor only within 45 days
after publication.  Metadata remains separately editable.  These are current
service rules, not guarantees about future Zenodo behavior.

The resource-type documentation says to choose the type that best represents
the significant uploaded object, and to split materially different resource
types into separate records when appropriate.  The license field is required;
Zenodo defaults to CC BY 4.0 and supports mixed-license uploads.  Creator
metadata supports personal names, ORCID identifiers, and free-text affiliation
entries.  Versioning is for updated files of the same record and produces a
separate, linked record version.

Official pages:

- <https://help.zenodo.org/docs/deposit/create-new-upload/>
- <https://help.zenodo.org/docs/deposit/describe-records/resource-type/>
- <https://help.zenodo.org/docs/deposit/describe-records/licenses/>
- <https://help.zenodo.org/docs/deposit/describe-records/creators/>
- <https://help.zenodo.org/docs/deposit/manage-versions/>

## Project judgment

Paper I is a publication/preprint object, while Zenodo record 21720863 is the
immutable v0.3.9 software release.  They are not versions of the same object.
Paper I should therefore be created as an independent Zenodo record with the
preprint as its primary resource and a minimal reproducibility supplement as
supporting files.  GitHub integration remains disabled; upload is manual so
that third-party PDFs, extracted text, and vendored archives cannot be swept
into the deposit.

The manuscript license is an author-owned legal choice and does not inherit
the repository's MIT software license automatically.  CC BY 4.0 is the
recommended manuscript candidate because it is Zenodo's documented default,
but it remains ungranted until the owner confirms it.  Software files retain
their existing MIT terms.  Publication date means the date the preprint first
becomes public, not the internal draft date.  Communities are left empty
unless membership and scope are confirmed.

## Boundary

This note prepares a draft-upload workflow only.  It does not reserve a DOI,
create or publish a Zenodo record, grant a license, authorize a Git push, or
claim that the current manuscript has passed every freeze gate.

The 2026-08-06 reference-manifest refresh ran in `--skip-text` mode because
`pypdf` is absent from the project environment.  Existing extracted text was
retained as a search aid and all locally archived PDFs were hash-checked; no
new paper PDF or extracted text was introduced by this Zenodo workflow audit.
