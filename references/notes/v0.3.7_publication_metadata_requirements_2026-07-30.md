## Implementation consequences

1. The JOSS draft should be 750–1750 words and include the currently
   required Summary, Statement of need, State of the field, Software design,
   Research impact statement, and AI usage disclosure sections.
2. The AI disclosure must identify the tool and scope of assistance, and
   must state that a human reviewed and remains responsible for the work.
   An AI system is not listed as an author.
3. JOSS requires an OSI-approved open-source license. This repository has no
   human-selected license at the time of verification. Metadata and paper
   drafts may be prepared, but publication readiness must remain blocked
   until the human owner selects and adds a license.
4. A root `.zenodo.json` can override metadata inferred from a GitHub
   release. A root `CITATION.cff` supplies portable citation metadata.
   Neither file means that a release was deposited or that a DOI exists.
5. v0.3.7 will prepare local metadata only. It will not create a GitHub
   release, submit to JOSS, deposit to Zenodo, or invent a DOI.
6. The short-report PDF was built with the portable Tectonic 0.16.9
   release following the official installation route. This records the
   build toolchain only; PDF text extraction and all six rendered pages were
   checked separately.
