# v0.4.2 Myrheim-Meyer calibration audit

Date: 2026-08-15

## Source check

The archived PDF `gr-qc-0309009v1_sorkin_causal-sets-discrete-gravity.pdf`,
PDF page 11, defines the ordering-fraction curve as

`f(d) = (3/2) * binomial(3d/2, d)^(-1)`.

Using the Gamma-function definition of the generalized binomial coefficient,
this is

`f(d) = Gamma(d+1) * Gamma(d/2) / (2 * Gamma(3d/2))`.

The independent archived control in
`gr-qc-0003117v4_rideout-sorkin_continuum-limit-causal-set-dynamics.pdf`
states the anchor values `f(2)=1/2` and `f(4)=1/10`.

`scripts/archive_references.py --skip-text` revalidated the local archive and
refreshed its hashes on 2026-08-15. The project `uv` environment did not contain
`pypdf`, so text was not re-extracted in that run; the equation above was also
checked directly on the rendered PDF page rather than trusted from extracted
text alone.

## Implementation consequence

The first v0.4.2 design draft used denominator `4`, which returned `1/4` and
`1/20` at those anchors. Forward evaluation and numerical inversion shared the
same incorrect expression, so a round-trip-only analytic control did not catch
the error. The design and measurement primitive now use denominator `2`, and
the bounded preflight must test the two external anchor values in addition to
round-trip inversion.

## Claim boundary

This correction validates the calibration formula only. It does not establish
that any finite candidate ensemble is manifoldlike, has a continuum limit, or
possesses a physical spacetime dimension.
