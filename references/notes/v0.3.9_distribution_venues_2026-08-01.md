## Distribution judgment

1. **Correct the public preview before adding it.** Do not expose the frozen
   v0.3.7 PDF as the current standalone preview: its author identity and DOI
   statement are stale. First re-export a metadata-correct PDF naming Kenichi
   Osaki and pointing to the v0.3.9 Zenodo DOI, while retaining the old PDF
   unchanged inside the frozen bundle. During Zenodo's current 30-day
   minor-file-correction window, the corrected PDF may then be added as a
   standalone file and selected as the default preview. The depositor should
   add a public note explaining that this is a metadata-corrected re-export of
   the frozen v0.3.7 scientific report; it is not the old file with its hash
   silently changed.
2. **Primary additional preprint channel: arXiv.** Prepare an arXiv-specific
   manuscript revision from the TeX source, with Kenichi Osaki/ORCID metadata,
   the Zenodo software DOI, and a stable GitHub release/commit link. The
   provisional category recommendation is primary `gr-qc`, with at most one
   justified cross-list such as `math-ph`. New submitters or new categories may
   require endorsement. TeX source, not the generated PDF alone, should be
   submitted.
3. **Indexing rather than reposting.** A `gr-qc` arXiv submission is in
   INSPIRE's regular ingestion route. Wait for ingestion and only use the
   INSPIRE request form if the record is missing after a reasonable interval.
4. **Do not submit the current short report to JOSS.** Besides the public-age
   gate, the current paper is centred on a new theorem, while JOSS requires the
   paper to centre reusable research software. Reassess only after sustained
   public development, outside use or credible community impact, and a
   software-focused paper.
5. **Do not multiply identical repository deposits.** Figshare, OSF, and HAL
   would mostly duplicate Zenodo/arXiv functions for this project. HAL can be a
   fallback archive, but its current trusted transfer to arXiv requires French
   academic affiliation and is not a general endorsement bypass.
6. **Optional code preservation.** Software Heritage's Save Code Now can archive
   the public GitHub origin and provide a software-preservation identifier. It
   is complementary to Zenodo, but it is not a readership or peer-review
   channel.

## Journal boundary

The current programme roadmap remains preferable to a stand-alone journal
submission of SR1. Integrate SR1 with the weak-semantics witness, one-sided
profiles, and genuine `n=5` stability into Paper I, then reassess Journal of
Mathematical Physics. AIP permits arXiv preprints but disallows inappropriate
fragmentation, so posting SR1 to arXiv now is compatible with the roadmap while
submitting overlapping SR1 and Paper I journal manuscripts would create an
avoidable overlap problem. Classical and Quantum Gravity remains conditional
on a later result with broader gravitational significance; its current Notes
article type does not by itself make the finite SR1 theorem the best strategic
submission.
