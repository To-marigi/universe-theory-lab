# Control/methods preprint Zenodo submission-policy note (2026-08-20)

## Source claims

Zenodo's official deposit documentation was rechecked on 2026-08-20. It
states that a new upload may contain up to 100 files and 50 GB, recommends an
archive for 20 or more files, allows the depositor to select the default
preview, and recommends open non-proprietary formats. The record description
may be an abstract with separate methods, technical-information, or note
descriptions.

Zenodo registers a DOI when a record is published by default. Advance DOI
reservation is optional and is needed only when the DOI must be placed in the
files before publication. The publication-date field is required and denotes
the date on which the upload is first made public; its UI default is the draft
creation date and therefore must be checked before publication.

The current file-correction documentation distinguishes two windows. Zenodo
recommends a new version for significant file changes. Minor file corrections
may be initiated within 30 days after publication, and the resulting file-edit
draft must be published within 45 days of the original publication date.

## Project application

The methods preprint uses a new Publication / Preprint record, not a new
version of the already-published Paper I record. The upload has exactly two
top-level files: a directly previewable PDF and a deterministic tar.gz
supplement. The official archive recommendation is not a ZIP-only requirement;
tar.gz is retained because the project verifier checks deterministic tar and
gzip metadata. The PDF is selected explicitly as the default preview.

No DOI is reserved in advance. The human depositor selects that the upload has
no existing DOI and lets Zenodo register one at publication. The actual first
public date is entered immediately before publication. The manuscript is CC BY
4.0; software in the supplement remains MIT licensed.

## Boundary

These service-documentation facts guide local package preparation only. They
do not create a Zenodo draft, reserve a DOI, upload files, publish a record, or
authorize a scientific claim. The local source records are metadata-only
because the cited pages are live official HTML documentation; the exact URL
and retrieval date preserve the version boundary used here.
