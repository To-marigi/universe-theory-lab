# 量子因果情報模型 v0

`spec.json` は探索可能な候補空間の境界です。作用の係数も、情報項の物理的正しさも
与えていません。特に `Phi_info` を足すだけで計量、重力力学、位相が導かれるとは
仮定しません。

v0 では次を分離します。

1. 因果順序 `C` — 光円錐と順序
2. 出来事数 — 体積の calibration
3. 状態 `rho` — 相関
4. チャネル `E` — 許された情報伝達
5. 疎な `Phi_info` — 反証対象となる候補作用

候補は最大四演算子に制限し、保留データで係数を再調整しません。一般の量子重力の
状態和が数学的に定義済みだとは主張せず、有限模型から順に検査します。
