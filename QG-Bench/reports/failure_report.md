# Failure report

このファイルには成功例を並べず、反証と未達を記録します。

## v0.1 で未達

1. 論文と同じ `N=18000, m=10` の全密行列計算は、v0.1 の通常 CI では実行しない。
2. cutoff `epsilon -> 0` と密度 `rho -> infinity` の二重外挿は未実施。
3. 収束次数と信頼区間は未確立。
4. 量子チャネルを因果辺へ割り当てたときの大域的整合条件は未形式化。
5. 相互情報量から AdS 距離を無仮定で復元していない。
6. 2+1 次元、BTZ、3+1 次元、重力子、標準模型は範囲外。
7. `Phi_info` を含む動的因果集合のサンプリングは未実装。

## 解消した不安定性

最初の保留曲率試験は二 seed のみで、`L=1.4` の RMSE が
`0.0244 -> 0.0594` と悪化し不合格になった。質量、cutoff、曲率、作用係数を固定したまま
六 seed・四密度へ拡張すると、最低密度から最高密度への比較は安定して改善した。
これは単調収束の証明ではなく、二 seed 判定が標本分散に弱すぎたことの記録である。

## 失敗時に保存する情報

- config、seed、Python/NumPy/SciPy 版
- 最初に失敗した密度と曲率
- ビン中心、標本数、平均、連続値、残差
- 係数再調整の有無
- cutoff と無効化した点対の数

機械可読な実行結果は `results/qgbench_v0.1.json` に保存します。
