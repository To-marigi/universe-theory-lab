# Reproduction report

## 対象

A. Kastrati and H. Hinrichsen, arXiv:2504.12919v1 の Eqs. (9), (16), (22),
(50), (51), (56) を、論文コードを使わず再実装します。

## 独立性

- 連続側: SciPy の一般次数 Legendre 関数
- 離散側: 因果行列と三角連立方程式
- 共通入力: 論文に記載された座標、体積測度、質量、曲率

同じ式を二つの数値ライブラリで評価しただけでは物理的な独立検算にならないため、
行列の定義方程式残差、質量ゼロ極限、ラベル不変性も別の回帰試験にします。

## 合否

固定結果を本文へ手入力しません。次を実行して
`results/qgbench_v0.1.json` の `acceptance` を参照してください。

```powershell
uv run python -m universe_lab.qgbench.cli
```

最小基準は、基準曲率と二つの保留曲率のすべてで、最高密度のビン RMSE が最低密度より
小さいことです。合格しても解析的連続極限や量子重力を証明しません。

`ads2_paper_mass_stress` は論文図と同じ `m=10` を用いますが、最大点数は `N=900`
であり、論文の `N=18000` 散布図の pixel-level 再現ではありません。
