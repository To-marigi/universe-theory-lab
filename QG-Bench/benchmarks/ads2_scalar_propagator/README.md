# ads2_scalar_propagator

1. arXiv:2504.12919v1 Eq. (50) で固定個数条件付き sprinkling を生成
2. Eq. (9) で因果行列を生成
3. Eq. (56) を三角連立方程式として計算
4. Eq. (16), (22) の連続解と固有時ビンごとの集合平均を比較

単一標本の散布図ではなく三 seed を合成し、最低密度から最高密度へ RMSE が減ることを
v0.1 の最小合格条件にします。これは収束次数の確立ではありません。

通常ゲートの `m=4` に加え、論文の図と同じ `m=10` を
`ads2_paper_mass_stress` で検査します。後者は `N=320,560,900` の四 seed であり、
論文の `N=18000` を再現したとは主張しません。
