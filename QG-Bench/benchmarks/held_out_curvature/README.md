# held_out_curvature

基準曲率半径 `L=1` とは別の `L=0.7, 1.4` を、係数再調整なしで評価します。
各半径で六つの事前固定 seed と四密度を使います。両方で最高密度のビン RMSE が
最低密度より減らなければ不合格です。中間密度の非単調性は隠さず結果 JSON に残します。

当初の二 seed 試験では `L=1.4` の RMSE が `0.0244 -> 0.0594` と悪化しました。
物理係数を変えず seed 数だけを増やした追試で標本分散と判明したため、v0.1 の固定規約を
六 seed としました。この監査履歴は、成功する seed だけを選んだのではないことを示すため
残しています。
