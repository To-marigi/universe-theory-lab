## 5. Conditional linear-algebra observations

For a residual operator family, any vector test set that spans `K^2` upgrades
equality on those vectors to operator equality. More generally, a vector is
enough when it is separating for the relevant residual subspace. Therefore the
weak/weak profile would enter a corresponding strong semantic profile if the
GC residuals or sourcewise MSR residuals were tested on a spanning/separating
set sufficient to lift that family to operator identities. Whether either
one-sided strong profile alone forces commutativity is currently open.

For MSR this condition is sourcewise: vectors tested against one residual
cannot in general separate a different source residual.
