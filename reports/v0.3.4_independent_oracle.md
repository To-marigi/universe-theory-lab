## What this establishes

Subject to the frozen finite compilers faithfully encoding their declared
relations, the n<=4 d=2 constraint system has an exact nonempty scalar
solution locus. In particular:

- this fixture is not rejected by any of the 783 compiled CPOBC equations;
- all 165 reconstructed transition matrices are invertible because each is
  a nonzero scalar multiple of `I_2`;
- the 24 strong-MSR and full local-GC inventories are mutually consistent
  at this fixture;
- each Eq. (113) source-index interpretation is separately consistent;
- the literal branch needs `Q_5`, and the oracle never leaks that assignment
  into the `Q_N` branch.

This is stronger than selected-relation or random-sample evidence: it is an
exact witness for every declared finite inventory above.

## What this does not establish

The witness lies in the central scalar subalgebra, so it cannot classify the
general noncommutative d=2 solution space. It does not prove that every
solution is scalar, describe all S1/S2/S3 loci, prove Tietze equivalence or
presentation minimality, extend the finite n<=4 compiler to arbitrary stage,
or resolve the source-index ambiguity by choosing one branch.

Accordingly the existence conclusion is exact but narrow:

```text
FINITE N<=4 D=2 SCALAR SOLUTION EXISTS
GENERAL NONCOMMUTATIVE D=2 CLASSIFICATION REMAINS OPEN
```

The oracle verdict therefore remains `INDEPENDENT_ORACLE_PARTIAL`.

## Generic symbolic chart route

The exact matrix representation is a pair `(N,d)` with value `N/d`. For a
generic symbolic 2-by-2 numerator the oracle verifies on both sides

```text
(N/d)^-1 = d adj(N) / det(N).
```

It declares one generic coordinate chart per structural stratum:

| Fixture | Stratum | Exact chart form |
| --- | --- | --- |
| `ORACLE_S1_FIXTURE_01` | distinct-eigenvalue | `R_j=diag(a_j,b_j)/d_j`, with `a_2-b_2 != 0` |
| `ORACLE_S2_FIXTURE_01` | common nilpotent | `R_j=(l_j I+m_j E12)/d_j`, with `m_2 != 0` |
| `ORACLE_S3_FIXTURE_01` | scalar | `R_j=(l_j/d_j) I` |

In every chart `Q_j=Q_1 R_j` for `j=2,3,4`, with a generic invertible
`Q_1`. The ratio matrices commute symbolically. The selected Eq. (120)
fixtures and selected Eq. (129) fixture vanish identically in all three
charts. Eq. (130) is not an identity on the generic S1 or S2 chart and is an
identity on S3. “Not an identity” does not eliminate S1 or S2; special loci
were not solved.

The generic branch discriminator still uses the synthetic `H_4=Q_4`. Its
purpose is only to prevent accidental merging of `[H_4,Q_4]` and
`[H_4,Q_5]`. The scalar full-inventory route, by contrast, evaluates the
actual 25+25 frozen atomisation branch words.
