## 2. Why the derived rank 131 still proves splitting

The exact kernel in both derived branches is

```text

```

This is not merely an accidental zero at the chosen base point.  The
cutoff-external `Q5` column is universally zero in each derived matrix:

1. `Q5` is not one of the 131 actual occurrence variables, so raw CPOBC rows
   do not contain it.
2. Fixed-vector GC paths and reachable-state MSR use actual transitions only.
3. Across all 25 derived Eq. (113) relations the only `Q` tokens are `Q_3`
   and `Q_4`; the number of `Q_5` token occurrences is zero.  For comparison,
   the literal branch has 48 `Q_5` token occurrences.
4. Stage-four Eq. (139) mentions `Q5` as `Q_(n+1)`, but its universal
   coefficient cancels.  For generic diagonal entries, exact symbolic matrix
   multiplication gives

   ```text
   coefficient_LHS(x_Q(n+1)) = a_left*a_right/b_Qn,
   coefficient_RHS(x_Q(n+1)) = a_left*a_right/b_Qn,
   difference                    = 0.
   ```

The only denominator here is `b_Qn`, already a unit on the nonsingular scalar
base.  The identity covers the three printed-strict and six completed
stage-four Eq. (139) instances.

It follows that a nonzero determinant in the 131 actual columns gives, on its
principal open,

```text

x_actual = 0,
ker M = span(e_Q5).
```

Thus promoting the derived rank-131 computation to an actual-transition
splitting theorem uses an independently certified universal column identity,
not an inference from rank at one point.
