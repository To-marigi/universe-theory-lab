## 1. 結論

宣言済み mixed ansatz の17次元可換終端は、無制限 source-native 955 系へは
昇格できない。理由は、到達状態 MSR を厳密に解いた非特異 slack chart の中で、
mixed ansatz が少なくとも **214本の独立な対角法線方向**を捨てているからである。

適用体は層別化する。以下の座標・rank による coverage gap は標数0の構造計数である。
一方、前段から引用する mixed ansatz の17次元終端 verdict は、その前段どおり
**`QQ` 限定**である。

構造的な座標数は次の通り。

```text
131個の一般 2x2 quotient operator + 48 slack
  = 524 + 48
  = 572 scalar coordinates

24個の timid matrix 定義を monic triangular に消去
  572 - 24*4 = 476 effective coordinates

107個の独立 non-timid matrix に mixed の対角を課す
  476 - 107*2 = 262 coordinates
```

最後の262は mixed manifest の `x/y` 座標数と一致する。ただし、消去された
24個の timid matrix にも mixed の対角形を課す必要があり、これはさらに48本の
導来対角 obligation になる。その48本のランクは本ゲートでは測っていない。

したがって確定したのは次の境界である。

- 214本は異なる自由座標そのものなので exact rank 214。
- mixed locus は無制限 slack chart の正余次元閉部分である。
- mixed 終端を「稠密だから一般にも成立」と延長することはできない。
- 無制限 source-native 955 は依然 `OPEN`。

## 2. slack chart が到達状態 MSR を覆う理由

二次元で非零ベクトル `v` を固定する。`J=[[0,-1],[1,0]]` とすると、

```text
R v = 0  <=>  R = u (Jv)^T
```

が任意の `2x2` residual `R` に対して成り立ち、`u` は一意である。
実際、各行 `(r0,r1)` は `r0*v0+r1*v1=0` を満たすため、

```text
v0 != 0: lambda = r1/v0,   r0 = -r1*v1/v0
v1 != 0: lambda = -r0/v1,  r1 = -r0*v0/v1
```

と書ける。二つの patch は `v!=0` を覆う。source transition が非特異で
`Omega!=0` なら canonical path 上の全到達状態も非零なので、この
parameterisation は非特異 reachable-state MSR locus 全体を覆う。

24個の timid residual に二成分の `u` を一つずつ導入するため slack は48座標。
各 timid matrix は互いに異なる monic pivot で解かれ、依存関係は非循環である。
よって96 scalar entries の消去は近似や局所線形化ではなく厳密である。

## 3. mixed ansatz の位置

mixed ansatz は各 quotient orbit `e` に

```text
A_e = [[p_e, x_[e]], [y_[e], 1]]
```

を課す。107個の独立 non-timid matrix については、各 `00` と `11` が互いに異なる
自由座標なので、

```text
A_e:00 - p_e = 0
A_e:11 - 1   = 0
```

の214本は exact rank 214 である。残る自由度は214個の off-diagonal entry と
48 slack、合計262。

一方、24個の timid matrix は既に recurrence で消去済みである。その定義を代入した
行列にも対角 `(p_e,1)` を要求する48 scalar obligation が残る。この全48本を含めれば、
非特異 reachable-state MSR chart 上で mixed locus と正確に一致する。ただし導来48本は
非線形になり得るため、本成果物はその独立ランクを主張しない。

## 4. substitution degree ceiling

solver を投入する前の構文的な次数上限を、非循環 timid recurrence に沿って伝播した。
独立 matrix entry の次数を1とし、状態 word の上限を matrix 上限の和、timid matrix を
`max(1, 1+deg(v_c))` とした。

| 対象 | 次数上限のヒストグラム | 最大 |
|---|---|---:|
| 24 source state | `0:1, 1:2, 2:3, 3:11, 4:2, 5:3, 7:2` | 7 |
| 24 timid matrix | `1:1, 2:2, 3:3, 4:11, 5:2, 6:3, 8:2` | 8 |
| CPOBC 783 blocks | `2:559, 3:140, 4:59, 5:25` | 5 |
| strong GC 320 blocks | `2:2, 3:17, 4:158, 5:65, 6:47, 7:15, 8:14, 11:2` | 11 |

これらは **substitution の構文的上限**であり、scalar entry 展開後に相殺が起きない
ことや、実際に最大次数の非零項が残ることは主張しない。
