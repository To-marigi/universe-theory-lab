# v0.4.1 reachable-state MSR soundness audit

Date: 2026-08-01

## Verdict

**(B) PROFILE MISREPRESENTATION; THE CLAIMED PROFILE PROOF IS INVALID.**

The 955-relation QQ computation is an exact calculation for the selected
Q-reconstructed system.  It is not a proof for the source-native
`strong GC + reachable-state MSR` profile.  The eliminated coordinates already
use the operator identity in Eq. (108), whose derivation uses strong-operator
MSR.  Removing the 21 residual records labelled `STRONG_OPERATOR_MSR` from the
ideal does not remove that assumption from the reconstruction map.

Consequently, the truth of commutativity for the intended profile is
**unresolved**, not disproved.  The profile result must be downgraded from
`PROVED` to `OPEN_PROFILE_SOUNDNESS_FAILURE` until a source-native weak-MSR
elimination or a valid lifting theorem is supplied.

## Formal direction of implication

Work in the occurrence-identification-ON source space and let:

- `C` be the nonsingular source assignments satisfying all source CPOBC
  equations and strong operator GC;
- `P` be the intended profile, namely the points of `C` whose MSR residual
  `D_c` obeys `D_c v_c = 0` on the declared reachable state at every source;
- `Phi` be the v0.3.2--v0.3.4 occurrence reconstruction through Eqs. (107),
  (108), and (112);
- `D_955` be the 955-relation direct system in Q coordinates, including its
  localisation predicates.

Dropping reachable-state MSR at source level gives the valid inclusion

`P subset C`.

For a sufficient no-go core, the eliminated system would have to cover `C`, or
at least every potentially noncommutative point of `P`.  What was actually
eliminated is

`Phi(D_955) subset C intersection image(Phi)`.

The extra condition `x in image(Phi)` is not a coordinate convention on `C`.
It includes Eq. (108) as an operator identity.  Reachable-state MSR does not
imply that identity.  The exact source point below proves that `P` is not a
subset of `image(Phi)`.

Thus, after lifting the Q solutions back to source occurrences:

- `Phi(D_955)` is a proper restricted slice of the intended ablation core `C`;
- it is **not a superset** of `P`;
- the present artifacts do not prove the converse inclusion
  `Phi(D_955) subset P`, because the 21 nontrivial MSR residuals are omitted.

The two spaces are therefore not currently certified as comparable relative to
`P`.  The only inclusion needed by the published forward rule, `P subset
Phi(D_955)`, is false.

## Exact source-native escape point

There is an exact rational point of the intended source profile outside the
Q-reconstruction image.  For every transition occurrence `t` at source stage
`n`, define

```text
A_t = diag(p_t, 1),
p_t = 2^(w-m) / 2^n,
```

where `w` is the precursor size and `m` is the number of maximal elements of
the precursor.  The first diagonal character is the CSG character `t_j = 1`;
the second character assigns one to every transition.  Take
`Omega = (1,0)^T`.

The focused exact test verifies:

| gate | exact result |
|---|---:|
| occurrence-identification ON | 165 records collapse consistently to 131 orbits |
| nonsingularity | 165 / 165 |
| denominator-cleared CPOBC | 783 / 783 zero |
| inverse-containing CPOBC | 712 / 712 zero |
| strong operator GC path pairs | 1,529 / 1,529 zero |
| reachable-state MSR | 24 / 24 zero on the reachable ray |
| strong operator MSR | 0 / 24; all 24 fail |

All reachable states are nonzero scalar multiples of `Omega`, so the MSR
residual-on-`Omega` calculation is exactly the source-state calculation.  At
the first source,

```text
D_p1 = sum_j A_1^j - I = diag(0,1),
D_p1 Omega = 0.
```

Every reconstructed assignment instead makes `msr:p1-0` the zero operator by
free-word identity.  The source point therefore belongs to `P` but cannot lie
in `image(Phi)`.  It is commutative, so it is a coverage counterexample, not a
noncommutative counterexample to the desired theorem.

## Effect on the QQ certificates

The 42 QQ chart certificates and their arithmetic checks need not be discarded.
They remain exact certificates for the two selected relation families inside
the frozen strong-profile Q reconstruction.  What fails is their semantic lift
to the two one-sided weak profiles.

For the 955 branch specifically, the sound conclusion is only:

> Every point of the frozen Eq. (107)/(108)/(112) Q-reconstructed 955-relation
> system has commuting `Q_1,...,Q_4`.

It does not imply commutativity for every source-native strong-GC / reachable-
state-MSR assignment.

The campaign-level verdict
`WEAK_D2_ON_ONE_SIDED_COMMUTATIVITY_PROVED` therefore cannot be used as a weak
semantics theorem.

## Companion defect in the 721 branch

The same audit exposes the symmetric issue in the other one-sided claim.  The
721-relation branch may use Eq. (108) because strong MSR is present, but its
Q-only reconstruction also uses Eq. (112), whose forward certificate is
explicitly restricted to strong operator GC.  Fixed-vector GC does not justify
that operator reconstruction.  Thus the 721 branch is also invalid as a proof
of `fixed-vector GC + strong MSR` unless a separate lifting argument is added.

Accordingly, both v0.4.1 one-sided truth values revert to `UNRESOLVED`; the
source-native triangular scouts remain bounded exact evidence only.

## Required repair

The safe repair is profile-specific compilation before any further solver run.

1. For `strong GC + reachable-state MSR`, retain source occurrence operators
   (at minimum the MSR-dependent timid degrees of freedom) and a fixed initial
   vector.  Encode `D_c v_c = 0` directly.  Eq. (107) and the strong-GC parts of
   Eq. (112) may be used only where their dependency proof remains valid; Eq.
   (108) may not be installed as an operator definition.
2. For `fixed-vector GC + strong MSR`, Eq. (108) is available, but non-antichain
   gregarious operators may not be eliminated through strong-GC Eq. (112).
3. Recompile each source-to-reduced map with an assumption ledger.  A relation
   family may be ablated only if it is absent both from the final ideal and from
   every coordinate definition used by that ideal.
4. Alternatively, add and state a spanning/separating condition that genuinely
   promotes the weak equality to an operator identity.  That proves a stronger
   conditional profile, not the original weak profile.

No solver was run for this audit.
