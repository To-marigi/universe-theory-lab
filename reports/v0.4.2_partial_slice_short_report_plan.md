## 1. 決定

`PROVED_PARTIAL_SLICE` は、一般 one-sided profile の未解決問題から切り離し、
**独立短報A（SR3b-A）**として執筆できるだけの閉じた定理・証明合成・再現成果物を持つ。
推奨形態は、まず版付きの standalone technical preprint を準備し、Paper I の補助定理群へ
統合できる状態にすることである。現段階では投稿・deposit は行わない。

この短報の価値は、strong GC + reachable-state MSR の一般 corner を解いたことではなく、
意味論監査で正当化できる proper reconstruction slice を厳密に切り出し、source-native
Eq. (120)、source-to-direct pullback、localisation、既存 exact chart certificates を
一つの定理へ再結合した点に置く。

### 仮題

日本語:

> 有限 CPOBC の再構成スライスにおける二次元可換性：source-native Eq. (120) と厳密チャート証明

英語:

> *Dimension-two commutativity on a reconstruction slice of finite CPOBC:
> a source-native Eq. (120) lemma and exact chart certificates*

短い running title:

> *Commutativity on a finite CPOBC reconstruction slice*

題名・要旨では `classification`、`sharp threshold`、`one-sided commutativity` を無限定に
用いない。`reconstruction slice`、`finite`、`n<=4`、`d=2` を可視化する。

## 2. 固定する主張

### 2.1 設定

- source stage: `n<=4`
- matrix dimension: `d=2`
- base field: characteristic zero。機械証明は `QQ` 上の exact arithmetic
- transition domain: 全 source transition が nonsingular
- occurrence semantics: `ON_QUOTIENT`
- GC: strong operator equality
- MSR: reachable-state equality
- Eq. (113): literal/derived branch を統合しない
- Eq. (139): printed-strict/completed domain を統合しない

\(P_{\mathrm{sGC+rMSR}}^{\mathrm{ns}}\) を、source-native CPOBC、strong GC、
reachable-state MSR、全遷移非特異性を満たす source assignment の集合とする。
\(U\) を 4 個の \(Q\) と 22 個の \(B\) inverse base が定義される open domain、
\(\Phi_U\) を凍結済み 165-occurrence rational reconstruction とする。
\(D_{955}\) は 700 CPOBC + 255 local-operator-GC 直接関係と 165 transition
nonsingularity predicate を満たす \(Q\)-側 locus である。

### 2.2 主定理

短報では、次の quantified form を主定理とする。

> **Partial-slice commutativity theorem.**
> 任意の
> \(x\in P_{\mathrm{sGC+rMSR}}^{\mathrm{ns}}\cap\operatorname{image}(\Phi_U)\)
> と、
> \(q\in U\) で \(\Phi_U(q)=x\) を満たす任意の preimage に対し、
> \(q\in D_{955}\) であり、
> \([Q_i(q),Q_j(q)]=0\) が全 \(1\le i<j\le4\) について成立する。

同時に次の包含を命題として明記する。

\[
P_{\mathrm{sGC+rMSR}}^{\mathrm{ns}}\cap\operatorname{image}(\Phi_U)
\subseteq \Phi_U(D_{955}).
\]

これは source point の全 preimage が監査済み 955 relations と localisation を満たす、
という forward direction である。逆包含は主張しない。

### 2.3 dimension-independent source-native lemma

補題は \(d=2\) より先に、unital associative algebra の units に対する自由語命題として
述べる。六つの antichain CPOBC Eq. (103)

\[
B_nQ_m=B_mQ_n\qquad(1\le m<n\le4)
\]

と必要な source nonsingularity から、任意の (2\le m<n\le4) について

\[
Q_nQ_1^{-1}Q_m=Q_mQ_1^{-1}Q_n
\]

が従う。Eq. (103) から Eq. (105) への右逆元操作、(B_1) の左消去、(Q_m) の
右乗法だけを使い、可換な並べ替え、trace、determinant quotient は使わない。

この補題は dimension-independent である。`d=2` 固有なのは、その後の
S1/S2/S3 simultaneous-form cover と QQ chart certificates である。

## 3. 証明の合成と固定 census

短報の proof spine は次の四段階に固定する。

1. 六つの raw CPOBC relations と nonsingularity から三つの `k=1` Eq. (120) を導く。
2. source CPOBC と strong GC を \(\Phi_U\) で独立に pull back し、\(D_{955}\) へ入ることを示す。
3. Eq. (120) と (det Q_1\ne0) から (R_s=Q_1^{-1}Q_s) (`s=2,3,4`) の pairwise
   commutation を得て、exact `d=2` S1/S2/S3 cover を適用する。
4. 21 exact QQ certificates と S3 structural certificate で全 noncommutative branch を閉じる。

### 4.2 novelty/priority status

現在の判定は `NOVELTY_PRIORITY_AUDIT_PENDING` である。

監査の検索範囲、数学的可換性文献、版管理、ローカル保存、NASバックアップ、

- arXiv:2603.25503 と後続版・引用文献・著者の follow-up
- CPOBC/QBC/QSG の finite-dimensional representation と operator-semantics literature

監査完了までは「project-certified partial theorem」または「本計算で得た部分定理」と呼ぶ。

## 8. Paper I への統合方法

Paper I の中心線は当面、SR1 の strong/strong commutativity と SR2 の weak/weak exact
noncommutative witness の非対称比較である。本短報Aは一般 one-sided corner の代用品ではなく、
次の順に補助モジュールとして統合する。

1. Paper I の source-relations 節へ dimension-independent Eq. (120) lemma を置く。
2. semantic lattice 節で full strong-GC/reachable-MSR corner を `OPEN` とした直後に、
   proper reconstruction-slice proposition を置く。
3. proof/certificate 節では 21/42 の再利用理由と 721 非使用を短報Aへ参照させる。
4. 結論では、proved slice を full corner の解決や sharp threshold に数えない。

将来 full955 が反例または no-go で解決しても、本短報Aは次のいずれかとして残る。

- full theorem の certified base slice / regression theorem
- complement (P\setminus\operatorname{image}(\Phi_U)) に必要な新機構を示す比較基準
- dimension-independent Eq. (120) provenance module

standalone preprint と Paper I の重複を管理するため、Paper I は短報Aを明示的に引用し、
証明の再録は要約と必要な補題に限定する。別々の査読誌へ細切れ投稿するかは、
novelty/priority audit と journal overlap policy の確認後に再判断する。

## 10. 投稿・deposit gate

### Gate A — internal draft complete

- 六節すべてが執筆済み
- 主定理と dimension-independent lemma が人間可読に証明済み
- 全 count/digest が machine artifacts と一致
- nonclaims と source/project provenance table が本文に存在

### Gate B — reproducibility complete

- clean environment で全 release commands が成功
- Eq. (120) と partial audit の JSON が byte/semantic digest で再現
- independent tests、mutation/fail-closed tests、static checks が成功
- frozen 21 certificates と oracle の hash が一致

### Gate C — novelty and priority complete

- targeted prior-art/citation audit が完了
- 一次資料が既に主張する Eq. (120) と project contribution の境界が査読可能な形で確定
- `first/novel` を使う場合は直接根拠を記録。根拠が無ければ使わない
- standalone 公開が Paper I を待つより合理的かを owner が再判断

### Gate D — release authorization

- title/abstract/conclusion が full955 または721を解決したように読めない
- public v0.3.9 と未公開 v0.4.x artifacts の版境界が明確
- Zenodo/arXiv metadata、license、source archive、checksum manifest が完成
- owner の新たな明示承認がある

### Gate E — journal submission, if pursued

- standalone journal article と Paper I 統合のどちらが適切かを novelty と overlap policy から再評価
- 投稿直前に journal scope/article type/policy を公式情報で再確認
- journal route を選ばない場合も、短報Aは versioned technical preprint と Paper I の証明入力として保存

現在通過しているのは theorem/certificate gate だけである。Gate A--E は未完であり、
この design 文書は公開、deposit、投稿、著者連絡を許可しない。
