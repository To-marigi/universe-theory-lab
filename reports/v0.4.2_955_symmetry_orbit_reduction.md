## 1. Part A: ゲージトーラス（確定）

mixed ansatz は

```
A_e = [[p_e, x_[e]], [y_[e], 1]],   p_e = CSG character (t_j=1)
```

である。`g_t = diag(t,1)` による大域共役は

```
A_e  ->  [[p_e, t*x_[e]], [t^-1*y_[e], 1]]
```

を与え、ansatz の形（対角成分 `p_e`, `1`）を保つ。したがって mixed locus は
`G_m` 作用を持つ。

### 帰結と非主張

- 不変量: `det(A_e) = p_e - x_[e]*y_[e]`（次数 0）、積 `u_[e] = x_[e]*y_[e]`。
- 関係多様体は `G_m` 軌道の合併である。
- 縮約効果は**大域パラメータ 1 個だけ**。patch `y_[e0]!=0` 上で `y_[e0]=1` と
  ゲージ固定でき、262 → 261 パラメータになる。辺ごとに 1 個ではない。
- **トーラスが ansatz の完全な安定化群であるとは主張しない。**
- **トーラス退化で pure 族には落ちない。** 重みは全 `x` に `+1`、全 `y` に
  `-1` なので、`t->0` では `x->0` と同時に `y->infinity` となり、アフィン
  チャート内に極限を持たない。したがって既証明の pure-lower global no-go を
  退化議論で mixed へ延長することはできない。mixed の obstruction は独自の
  証明を要する。

## 2. Part B: 組合せ的対称群（否定的終端）

### 定義

方程式系の対称性とは、131 個の ON transition orbit の置換 `sigma` であって

1. CSG character `p`、stage、transition kind を保存し、
2. `Q_1, ..., Q_4` の各々を保存し、
3. CPOBC (783)、strong_GC (320)、reachable_state_MSR (24) の各方程式集合を
   それ自身に写す

ものをいう。patch `y_[e]!=0` と `y_[sigma e]!=0` が互換なのは、この意味の
`sigma` が存在するときに限る。

`Q` を固定色に留める（pin する）理由は、可換子の標的が `Q_1,...,Q_4` で
書かれているからである。`Q` を動かす置換は witness を patch 間で輸送しない。

### 計算

orbit / equation の二部接続構造に対する equitable refinement（安定彩色）を
計算した。接続ラベルは**辺の左右を区別しない**。対称性は残差の両辺を交換
しうるので、side を付けたラベルは対称群より細かくなり、自明性の証明に使えない。
粗いラベルは結論を弱めることはあっても不健全にはしない。

| ラウンド | orbit 色数 | equation 色数 |
|---|---|---|
| 初期 | 23 | 5 |
| 1 | **131** | 228 |
| 2 | 131 | 983 |
| 3 | 131 | 983（安定） |

安定彩色は**離散**（131 色 / 全クラスがシングルトン）。

stable partition sha256: `253194f3f33e04e409d9a100db1c8ae0e78e24c47ebae86eee54a6570b1bdaf6`

### 健全性

彩色は真の対称軌道の**粗化**である。したがって

- 離散 ⟹ 任意の対称性が全 orbit を固定 ⟹ **対称群は自明**、
- 非離散の場合はクラスは軌道ではなく上界にすぎず、2 つの patch を同一視する
  には明示的な置換を出力し、全方程式多重集合の再写像で検証する必要がある。

今回は離散なので前者。**明示置換証明書の発行数は 0 で、必要もない。**

ただし認証したのは**単語レベルの組合せ的対称性のみ**である。多項式レベル、
あるいは関係多様体の非線形自己同型は分類していない。この抽象化が見落とす
係数レベルの偶然を排除するものではない。

## 4. 戦略上の含意

これは計画判断であり、どちらの終端が真かについての数学的主張ではない。

- 対称群が自明である以上、131 patch は互いに非互換であり、patch ごとの
  witness 探索は 131 個の独立な非線形問題を解くことに等しい。対称性による
  節約は存在しない。
- 一方、一様な obstruction 論証は patch 数に鈍感である。したがって本ゲートの
  否定的結果は、witness 終端に対する **obstruction 終端の相対価値を上げる**。
