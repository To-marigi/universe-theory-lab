## 0. 前提の再検証

**reachable-state MSR はこのチャートに恒等的に組み込まれている。** slack
compiler の `raw_source_system.reachable_MSR` は
`constraints_after_substitution: 0`、理由は `(J v_c)^T v_c = 0`。timid slack
recurrence `T_c = I - Σ A + u_c (J v_c)^T` が MSR を恒等的に解く。

したがって本チャートの core は **CPOBC + strong GC のみ**であり、以下の全ランクは
その core に対して計算されている。この事実を仮定せず毎回検証する。

### 1.1 自然な推測は外れる

正の重みを持つのは右上行列成分だけではない。**slack 座標 `u:*:0` も重み +1** を
持つ。仮定していたら分解の記述を誤っていた。導出したことが直接効いた箇所である。

### 1.2 解空間16次元の正体

自由度16は、**core のどの単項式にも現れない16座標**（`u:*:0` が8本、`u:*:1` が8本）
に一致する。そしてこの16本は、独立に凍結済みの
[`v0.4.2_955_slack_csg_tangent`](v0.4.2_955_slack_csg_tangent.md) が
`terminal_slack_blind_directions` として記録した16座標と**完全に一致する**
（成果物に `equals_the_frozen_terminal_slack_blind_directions: true`）。

core の単項式に一度も現れないことが、それらが blind である代数的な理由である。

## 2. upper stratum の分解（本ゲートの主結果）

**upper stratum** を `{107個の左下座標 A:*:10 が全て0}` と定義する。

重み付けから直ちに、そして機械検証により:

| 主張 | 反例数 |
|---|---|
| `(1,0)` ブロックは恒等的に消える | **0** |
| `(0,1)` ブロックは正重み族に厳密線形 | **0** |
| 対角ブロックは重み付き座標を一切含まない | **0** |

streamed 非零 core 成分 4,152 件すべてに対して検証した。

### 2.1 分解の内容

> **無制限 955 profile の upper stratum は、重み0座標のスカラー多様体 `S` の上に、
> 正重み座標の affine 線形ファイバーが乗ったものである。**

| | 座標 | 成分 | 項数 |
|---|---|---|---|
| スカラー系 `S` | `A:*:00`, `A:*:11`, `u:*:1` | 1,814 | 9,673 |
| 正重みファイバー | `A:*:01` (107) + `u:*:0` (16) = 123 | 1,038 | 16,004 |

スカラー系の次数分布は 2:1153, 3:95, 4:436, 5:61, 6:45, 7:16, 8:7, 9:1。

ブロック別内訳:

```
CPOBC     : lower_left 783 / scalar 1304 / upper_right_linear 783 / stratum上で消滅 262
strong_GC : lower_left 255 / scalar  510 / upper_right_linear 255
```

これは gate 2 の大域双線形簡約と同じパターンを、**ansatz なし・対角を固定せず**、
無制限チャート上で再現したものである。

- **upper stratum は無制限 955 profile ではない。** 両方の非対角族が非零である

  判定していない**。

  義務、そして **reachable visibility** が別途必要である。到達スパンが rank 1 の
  operator-only witness は、既知の SR2 の弱点を再現するだけである。
- stratum 上の obstruction も、宣言済み955三終端のどれにも到達しない。
- 全体判定 `FINAL_THEORY_OPEN` は不変。

## 7. 次のゲート

`DECIDE_THE_SIX_UPPER_RIGHT_COMMUTATOR_FORMS_AGAINST_THE_CORE_ROW_SPAN_ON_S`

`S` の厳密点上で、6本の可換子形式が正重み線形系の row span に入るかを判定する。
これは厳密線形代数であり、Gröbner も予算も要らない。二分岐:

- **span に入る** → その点で可換性が強制される（obstruction 側の証拠）
- **span から外れる** → その点で線形系を解くことで **955 witness 候補**が得られる

`Q` の対角が自由なため `(a00 - a11)` は一般に非零であり、可換子形式は generic に
非零である。したがって **WITNESS 側に転ぶ可能性を排除していない**。両終端を
terminal 形に設計してから実行すること。mixed ansatz の upper family が可換だった
のは対角を `(p_e, 1)` に凍結していたためであり、その直観をここへ持ち込まない。
