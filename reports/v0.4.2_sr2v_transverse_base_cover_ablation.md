## 4. Source-native Eq. (120) reduces six commutators to three

The frozen source-provenance certificate derives, using raw CPOBC and
nonsingularity only,

```text
T_mn = Q_n Q_1^-1 Q_m - Q_m Q_1^-1 Q_n = 0,
2 <= m < n <= 4.
```

Each `T_mn` is generated by exactly three raw CPOBC equations.  In the flattened
783-row inventory the six source rows are

| row | zero-based index |
|---|---:|
| `F21` | 0 |
| `F31` | 4 |
| `F32` | 29 |
| `F41` | 44 |
| `F42` | 147 |
| `F43` | 548 |

The exact free-algebra and upper-right identities are

```text
B1*T_mn = F_nm - F_n1*Q1^-1*Q_m + F_m1*Q1^-1*Q_n,
t_mn = A_B1^-1*(f_nm-(b_m/b1)*f_n1+(b_n/b1)*f_m1),
t_mn = -(b_m*b_n/a1)*E_mn,
E_mn = (r_m-r1)*(z_n-z1)-(r_n-r1)*(z_m-z1).
```

All prefactors are units.  Writing

```text
c_ij = (r_i-1)z_j-(r_j-1)z_i,
```

symbolic expansion gives the three identities

```text
c_mn = E_mn + c_1n - c_1m.
```

Therefore, modulo raw CPOBC, adjoining all six Q-commutator rows is globally
equivalent to adjoining the three-edge star `c12,c13,c14`.  Three is globally
minimal: on `r1=r2=r3=r4=r!=1`, all `E_mn` vanish while the star has rank three.

There is a sharper complete cover:

| locus | target needed after Eq. (120) |
|---|---|
| `U2=D(r2-r1)` | `c12` |
| `U3=D(r3-r1)` | `c13` |
| `U4=D(r4-r1)` | `c14` |
| `D_equal_nonunit=V(r2-r1,r3-r1,r4-r1) intersect D(r1-1)` | `c12,c13,c14` |

The omitted remainder is `r1=r2=r3=r4=1`, already inside `Z_Q`.  On `U_k`,
Eq. (120) makes all four points `(r_i,z_i)` lie on an affine line.  A single
star row kills its affine-intercept obstruction and hence all six
commutators.
