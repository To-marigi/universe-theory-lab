## 1. 結論

プロジェクトは継続する。ただし第一論文の中心を、広い意味での「`d=2` CPOBC
可換性分類」から、次の意味論的問題へ移す。

> 固定初期状態または到達状態上の等式は、どの作用素関係を観測・分離でき、
> どの追加条件のもとで作用素恒等式と可換性を回復するか。

この再焦点化には三つの理由がある。

1. Srivastava--Surya の Eq. (31)--(33) は、到達状態上の MSR から作用素 MSR への
   promotion を明示的な意味論上の継ぎ目として残している。
2. Xu, arXiv:2607.26672v1 は self-adjoint finite CPOBC と複数の二次元
   triangular/extension rigidity を先に広く扱う一方、non-self-adjoint nonsingular
   transition と state-only covariance を未解決方向として残している。
3. 現在の SR2 は exact な論理的 separation だが、reachable span が一次元で、全ての
   `Q` commutator がその ray を消す。したがって「状態上で観測できる非可換性」まで
   証明したとは言えない。

このため、Xu と broad rigidity を競うのではなく、non-self-adjoint な弱意味論、
observable/separating conditions、exact certificate を本プロジェクトの独自軸にする。

## 3. SR2-V: 到達可能性と非可換性の観測階層

固定初期ベクトルを `Omega`、許された path product を `P_alpha` とし、宣言した有限系で

`Reach(Omega) = {P_alpha Omega}`

とおく。各 witness は少なくとも次を別々に記録する。

1. `operator_noncommutative`: ある `i<j` で `[Q_i,Q_j] != 0`;
2. `reachable_span_rank`: `span Reach(Omega)` の exact rank;
3. `reachable_visible`: 宣言した stage/source-compatible test domain のある `v` で
   `[Q_i,Q_j]v != 0`;
4. `residual_visibility`: 各 GC/MSR residual のうち、到達状態が検出するものと
   消してしまうものの inventory。

現在の SR2 witness は厳密に

`operator_noncommutative = true`,
`reachable_span_rank = 1`,
`reachable_visible = false`

である。これは有効な論理反例だが、到達 ray の外側に非可換性を保持する
`off-reachable-sector separation` と表現する。

次の強化目標は、rank two と reachable visibility をともに満たす exact rational witness
である。ただし stage/source compatibility を定義せず、任意の reachable vector に任意の
`[Q_i,Q_j]` を作用させただけの結果を物理的可視性とは呼ばない。

SR2-V の終端判定を次に固定する。

- `REACHABLE_VISIBLE_NONCOMMUTATIVE_WITNESS_CERTIFIED`
- `REACHABLE_VISIBLE_NONCOMMUTATIVITY_OBSTRUCTED`
- `REACHABLE_VISIBILITY_OPEN_RESOURCE_LIMIT`

二番目を使えるのは、宣言した profile と visibility domain を exact に被覆した
obstruction proof がある場合だけである。bounded ansatz の no-go はその ansatz 名を付け、
一般 obstruction へ昇格しない。

## 4. SR3b-M: 最小回復条件の正しい定式化

source `c` の admissible residual が属する project-specific linear space を `R_c`、
その source で試験される状態を `v_c` とする。評価写像

`ev_(v_c): R_c -> K^2, D |-> D v_c`

が injective であることは、`R_c` 上で statewise equality を operator equality に
promote するための必要十分条件である。full `M_2(K)` 上の separating vector を要求する
必要はなく、逆に cyclicity だけではこの injectivity は従わない。

同じ residual `D_c` が二つの独立ベクトルを消すなら、`d=2` では `D_c=0` である。
ただし、通常の single-`Omega` GC は各 source に一つの状態 `v_c` しか与えない。
異なる source の reachable vectors が大域的に `K^2` を張っても、それだけでは別々の
residual `D_c` を operator identity に promote できない。したがってこの条件は
「通常の reachable span」ではなく、同一 residual を試す **multi-probe / multi-preparation
sourcewise spanning condition** と呼ぶ。

可換性証明の終点としては、ある non-scalar `Q_k` を exact に認証し、全 `Q_i` が
`Q_k` と可換であることを示せばよい。`2 by 2` centralizer が `K[I,Q_k]` なので、全ての
`Q_i` は同じ可換二次元代数に入り、pairwise commutativity が従う。

これらの線形代数事実は標準的だが、CPOBC residual inventory、semantic profile、
source binding まで結合した project theorem/certificate は未作成である。作成前に
`CERTIFIED` と記載しない。
