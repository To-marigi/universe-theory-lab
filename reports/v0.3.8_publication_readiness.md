# v0.3.8 publication readiness

Status: **BLOCKED**

The canonical-LF migration is locally complete. The field-aware bridge
reconstructs all 1,007 historical raw-byte bindings to 207 CRLF-era text
artifacts, the frozen Phase 1 and Phase 2 scientific gates pass on the LF
checkout, and the v0.3.8 release manifest regenerates exactly. No Sage
calculation or scientific verdict was changed.

## Resolved locally

1. Tracked text is canonical UTF-8 with LF; CRLF and lone CR are rejected by
   a repository-wide regression test.
2. Artifact writers explicitly use `newline="\n"`.
3. Wheel files are marked binary and the previously altered wheel matches the
   Git blob and passes ZIP validation.
4. The historical v0.3.7 manifest is retained rather than rewritten. Its 159
   entries are classified as unchanged bytes, declared bridge targets, or
   explicit v0.3.8 support/writer changes, with no unexplained entry.
5. `scripts/reproduce_v038.py` verifies the bridge, the unchanged scientific
   gates, and the new canonical-LF release manifest without rerunning Sage.

Local evidence on 30 July 2026: the full suite passed 341/341 tests, Ruff
passed, the v0.3.8 reproducer and 193-file manifest regenerated exactly, and
tracked CRLF/mixed-EOL counts were both zero. The advisory mypy result remains
the documented 11 pre-existing errors in one solver module.
