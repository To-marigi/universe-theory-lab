## 0. Gate 18 が残した12列の正体

[minor cover preflight](v0.4.2_955_minor_cover_preflight.md) は非Q列119本中107本に
構造的単項式マッチングを見つけ、残り12本を未解決として「finite minor cover が
必要」と結論した。本ゲートはその12本が何かを特定し、証明書までの距離を大幅に
詰める。

**列の配置**：列0–106 が `A:*:01`（上三角行列成分、107本）、列107–122 が
`u:*:0`（slack、16本）。**未マッチの12本は全て slack 座標**であり、行列成分側の
103本（非Q）は全てマッチ済みだった。

## 1. 必要なのは12本ではなく4本

非Q ブロックのランクは **111**、マッチ済み107列だけでランク **107**。したがって
追加で必要なピボットは **ちょうど4本**である。

3つの独立な非退化点で計測し、**毎回まったく同じ4列**が使われた：

```
u:p2-2:0    u:p3-006:0    u:p3-024:0    u:p3-026:0
```

残る8本（`u:p4-0002:0` 他、**すべて終端 p4 段**）は一度もピボットにならない
自由方向である。終端段の slack には下流の制約がないことと整合する。

### 計測上の注意（実際に踏んだ罠）

最初 `first=second=(1,1,1,1,1)` で計測して rank 103 を得た。これは**スカラー
退化点**（両対角が等しく全行列が単位行列のスカラー倍）で、Gate 15 が rank 103 /
ファイバー20 と記録済みの特異点である。非退化点の rank 114 とは別物であり、
これを使うと必要ランクを過小評価する。成果物では対照点として明示的に除外し、
その理由を記録している。

## 2. 4本とも source-localizer 単元に因数分解する

```
u:p2-2:0    ->  v423 * (v172 - 1)
u:p3-006:0  ->  v123 * v424 * (v172 - 1)
u:p3-024:0  ->  v172 * v271 * (2*v52 + v88 - 1)
u:p3-026:0  -> -v143 * (v172 - 1) * (v312 + v424 - 1)
```

各因数は、整数単元、単一の source 対角座標（`A:*:00` / `A:*:11`）、あるいは
**source 行列の対角成分そのもの**（`1 - α_{Q1}` や `1 - 2α - α` の形。これらは
timid 行列の対角成分である）のいずれかであることを機械照合した。

upper stratum では全ての source 行列が上三角なので

```
det(A_e) = A_e[0][0] * A_e[1][1]
```

であり、**131個の source determinant で局所化すれば全ての source 対角成分が
可逆になる**。したがって上記の因数は全て単元である。

## 3. マッチングを単元辺へ広げると111に届く

単項式辺（1単項式のみ）ではなく **localizer 単元辺**（係数が上記の意味で単元）
でマッチングを取り直すと：

| | |
|---|---|
| 単元行を持つ列 | **111** |
| 最大マッチング | **111** |
| 必要ランク111との一致 | ✔ |
| 行の相異性 | ✔（111行すべて異なる） |
| 未マッチ列 | 8（全て `u:p4-*:0`、単元行が1本も存在しない） |

未マッチの8本はそもそもピボットに不要な自由方向なので、これで**必要な111本
すべてが単元係数で異なる行にマッチした**ことになる。

## 4. しかし単元行列式は**まだ証明できていない**

ここは誠実に書く。**単元エントリのマッチングがあっても、行列式が単元とは限らない。**
行列式は置換にわたる符号付き和であり、単一の積ではない。単元行列式を得るには
選んだ小行列が置換三角（permutation-triangular）である必要がある。

疎な台を優先する選択で三角化を試みた結果：

| | |
|---|---|
| 選択した列 | 111 |
| 厳密に三角なステップ | **98** |
| 選択時の最大残余台 | 2 |
| 三角に足りないステップ | **13** |

**98/111 まで到達したが閉じていない。** `determinant_unit_status.certified` は
`false` であり、localized row-module 証明書は発行していない。

## 5. Gate 18 から何が解決したか

> Gate 18 は非Q列12本を構造マッチングなしのまま残し、finite minor cover を要求した。
> その12本は全て slack 座標であり、8本は如何なる消去でも使われない自由方向、
> 残る4本はそれぞれ source determinant 局所化で単元になる係数を持つ。
> マッチングを単元辺へ広げると、必要ランク111を異なる行の上で完全に達成する。

## 8. 次のゲート

残っているのは**13ステップ分の三角性**だけである。三角化可能な行選択を探すか、
行列式を別の方法（例：選んだ111×111の置換和を直接評価、あるいは Schur 補元）で
評価する。どちらも有限の問題である。

閉じれば、非Q消去が局所化環全体で一様に有効になり、`Λ` の membership は
Eq120 崩壊補題が既に記号的に与えた4列の問題に帰着する。閉じなければ、
`MISSION.md` の停止規則に従い 955 を `RESOURCE_LIMIT_OPEN` で凍結して 721 へ移る。
