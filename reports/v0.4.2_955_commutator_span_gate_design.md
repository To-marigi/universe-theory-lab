## 1. 何を判定するか

upper stratum 上で、core の `(0,1)` ブロックは 123 個の正重み座標
（`A:*:01` 107本 + 実際に現れる `u:*:0` 16本）に厳密線形である。スカラー多様体
`S` の点 `s` を固定すると、その点上のファイバーは

```
L(s) · w = 0,    w ∈ Q^123
```

という斉次線形系になる。6本の `Q` 可換子もまた同じ座標の線形形式
`c_k(s) · w`（各4項）である。したがって:

> `s` 上のファイバー全体で `Q` が可換 ⟺ 6本すべての `c_k(s)` が `L(s)` の
> row span に入る。

これは厳密線形代数であり、Gröbner も saturation も予算も要らない。

## 2. 判定文字列（事前固定）

### 点ごとの判定

- `V042_955_UPPER_STRATUM_COMMUTATOR_FORMS_IN_CORE_ROW_SPAN_AT_POINT_CERTIFIED`

  6本すべてが span 内。その点上のファイバー全体で `Q1,...,Q4` は可換。

- `V042_955_UPPER_STRATUM_COMMUTATOR_ESCAPE_AT_POINT_CERTIFIED`

  少なくとも1本が span 外。`L(s)` の核に、その形式を非零にするベクトルが存在し、

### 集合としての判定

有限個の点の評価から stratum 全体の結論は出ない。したがって:

- `V042_955_UPPER_STRATUM_SPAN_POINTWISE_EVIDENCE_ONLY_NONTERMINAL`

  評価した点の一覧と各点の判定を記録するのみ。stratum 全体を主張しない。

`S` 全体にわたる主張を出せるのは、`L(s)` の row span への所属を `s` について
**一様に**（記号的に、または `S` の被覆の上で）証明した場合だけである。その場合に

## 3. どちらに転ぶか予断しない

**WITNESS 側に転ぶ可能性を排除していない。**

upper triangular な `Q_i = [[a_i, b_i], [0, d_i]]` に対し
`[Q_i, Q_j]` の `(0,1)` 成分は

```
(a_i - d_i) b_j - (a_j - d_j) b_i
```

である。対角が自由なので `(a_i - d_i)` は一般に非零であり、この形式は generic に
非零である。

**mixed ansatz の upper family が可換だったのは、対角を `(p_e, 1)` に凍結して
いたためである。その直観をここへ持ち込まない。** 現行の obstruction 本命という
方針は計画上の賭けであり、この計測の結果より優先されない。

## 4. escape が出た場合に残る義務（fail-closed）

span 外が出ても、それだけでは 955 の三終端のどれにも到達しない。次を**すべて**
満たして初めて witness を名乗れる。

1. **非特異性。** stratum 上では `det(A_e) = A:e:00 · A:e:11` なのでスカラー条件。
   165 occurrence / 131 quotient localisation を全検査する。
2. **`N != 0` ゲート。** 残差が零作用素にならないこと。
3. **Eq113 / Eq139 の義務。** derived/literal × strict/completed の4分岐。core には
   含まれていない。
4. **reachable visibility。** 宣言済み三終端は
   `REACHABLE_VISIBLE_...` である。到達スパンが rank 1 の operator-only な非可換性は
   既知の SR2 の弱点を再現するだけで、終端に届かない。**構成した点で
   `reachable_span_rank` と `reachable_visible` を必ず測る。**
5. **厳密有理性。** 浮動小数点は証明にならない。

これらを満たさない段階では
`V042_955_UPPER_STRATUM_ESCAPE_WITNESS_CANDIDATE_OBLIGATIONS_OPEN` を使う。

## 5. in-span が出た場合の限界

- stratum 上の可換性は、**無制限 955 の可換性ではない**。両非対角族が非零である
  mixed 点は open のままであり、ゲージトーラスは片側を膨張させ他方を縮小するため、
  退化で mixed 点を stratum に落とすことはできない。
- したがって in-span は obstruction 側の**証拠**であって、
  `REACHABLE_VISIBLE_NONCOMMUTATIVITY_OBSTRUCTED` ではない。
- 有限個の点で in-span でも、`S` 全体では言えない（§2）。

## 6. 評価する点について

現時点で確実に使える `S` の厳密点は、対角 CSG 基点である。この1点だけでの結論は、
先行の tangent 監査が既に first-order で示した内容と重なる可能性が高く、**それ
自体は新規性を持たない**。

本ゲートの価値は、**対角が異なる点**での評価にある。それには `S`（238個の重み0
座標、1,814式、最大次数9）の点を追加で得る必要があり、これは別途の作業である。
`S` は非 timid 部分が二項式的（対角行列の積）で、timid 部分が加法的という構造を
持つ。この構造を使った点の生成は本ゲートの後続とする。

したがって本ゲートの成果物は、
**判定機構そのもの + 現在利用可能な厳密点での評価**であり、点の集合が小さいこと
自体を主張境界として記録する。
