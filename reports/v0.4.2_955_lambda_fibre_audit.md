## 結論

前ゲートの `Lambda=0` の数値 cross-check は、`A:*:01` を全て0にした
zero-section の評価だった。この監査では、同じ `L` の kernel から **Q 成分が非零の
ファイバー方向**を再構成し、`Lambda` が消えることを独立に確認した。

さらに、第一対角を成長特性 `(1,1,1,1,t)`、第二対角を全遷移で共通値 `s` とする
二変数族を `QQ(t,s)` 上で構成した。この族では、4,152個の scalar core 成分が恒等的に消え、
非Q列消去後の純Q行空間に `Lambda` が恒等的に入る。

これは非自明な一様性の証拠だが、**scalar variety `S` 全体の一様証明ではない**。
成果物は `full_S_claim=false` とし、全体判定 `OPEN` を維持する。

## 点wise 監査

各点で、upper-stratum の `(0,1)` core 行列 `L`（1038行・123列）を再構成した。
119本の非Q列を消去すると、次の会計になった。

```text
non-Q pivot rank       111
pure-Q residual rows   706
pure-Q residual rank     3
```

4点すべてで `D=a_1 d_4-a_4 d_1` は非零、`Lambda` 行の純Q行空間に対する残差は0だった。
また、`ker(L)` からQ成分が非零の方向を1本ずつ選び、直接 `Lambda` を評価した。

| 点 | `D` | `(b_1,b_2,b_3,b_4)` | `Lambda` |
|---|---:|---:|---:|
| `(1,1,1,1,1)` | `7/16` | `(1/24, 1/16, 7/96, 5/64)` | `0` |
| `(1,2,3,5,7)` | `17/54` | `(5/54, 35/288, 25/189, 265/1944)` | `0` |

4,152個の core 成分の評価失敗は各点で0だった。

## 記号的二変数族

第一対角を成長特性 `p(t)`（結合 `(1,1,1,1,t)`）、第二対角を全131遷移で共通値 `s` とし、
timid の `u:*:1` は source-native recurrence から厳密に解いた。`QQ(t,s)` 上で次を確認した。

```text
core failures              0
upper-right rows        1038
non-Q pivot rank         111
pure-Q residual rows     706
pure-Q residual rank       3
Lambda row remainder       0
D                         s*(t+13)/(2*(t+15))
```

従ってこの族では、少なくとも `s != 0`、`t != -15,-13` と既存の成長分母・到達積を
除く開集合上で、`Lambda` は一様にrow-spanへ入る。`s=2` は前回の一変数監査を再現する。
ここで第二対角を一つの共通値として動かしただけであり、131個の第二対角を独立に動かした
主張ではない。

## `D=0` 退化枝のアンカー点

`D` を割らずに、成長族の `t=-13`、第二対角 `s=2` を直接評価した。この点では
`D=0` だが、4,152個の core 成分は全て0、131個の source determinant も全て非零であり、
従って source-native の非特異性は保たれる。`L` の会計は同じく 1038 行、非Q pivot rank
111、pure-Q rank 3 で、`Lambda` の純Q row-module 残差は0だった。Q-visible kernel方向
の一例は

```text
(b_1,b_2,b_3,b_4) = (3/56, 1/16, 15/224, 3/56)
Lambda = 0
```

ここで示したのは `D=0` 全体の解決ではなく、アンカー除外で見落としていた枝上の
**非特異な一点**での直接 row-span 監査である。`D=0` の rank-2/rank-1 分岐を一様に
覆う別アンカー・証明書はまだない。

## 何がまだ未解決か

`S` は weight-zero 座標 `A:*:00, A:*:11, u:*:1` のscalar varietyであり、今回の成長族が
`S` 全体を覆うことは証明していない。未証明なのは次である。

- `S` の既約性・reduced性・成長族のZariski稠密性。
- 全 `S` 上で `Lambda` がrow-spanへ入ること。
- `D=0` 退化枝の全体。非特異なアンカー点1点は確認したが、対角行列のrank 2/1分岐を
  一様に覆う別アンカー・証明書は未構成。
- `D!=0` かつ `Lambda!=0` のcore fibre witness。

したがって、今回の判定は obstruction の終端ではなく、次の二択を狭めた中間ゲートである。

```text
1. 全Sのscalar idealとsource determinant localizationを含む
   localized row-module certificate を作る。
2. その証明が閉じなければ、D!=0 と Lambda!=0 を同時に満たす
   exact core fibre point を探す。
```

10パラメータの二特性族全体での記号消去は式膨張で予算外となったため、今回の証明書には
この二変数族だけを採用した。これは全Sへの外挿を意味しない。
