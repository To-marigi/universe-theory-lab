# v0.4.2 known-error boundary and safe remediation

Date: 2026-08-06

## Decision

The current Paper I candidate keeps the frozen `d2_sage_backend_v035.py` bytes
unchanged. The file is simultaneously bound by the v0.3.8 line-ending bridge,
the v0.3.9 release manifest, and the v0.4.2 source-to-direct provenance audit.
It is proof-bearing legacy solver code, not an active Paper I implementation
surface.

The 11 mypy diagnostics in that file remain an **advisory typing debt** for the
current release lane. They are not reclassified as a clean result by a broad
`ignore_errors` or a generated Sage stub.

## Why the apparent type-only patch was not merged

A minimal trial patch changed only timeout-string normalization, a one-shot
basis variable name, local annotations, and platform-conditional resource
lookups. Its focused d2 tests passed, but it left four Ruff B009 diagnostics and
changed the backend raw SHA. As a result, the v0.3.8 bridge and the v0.4.2
source-to-direct audit became stale. The trial was reverted; the frozen SHA and
all current release provenance are intact.

The current v0.4 tree is not a v0.3.9 checkout, so running
`scripts/reproduce_v039.py` from this tree is intentionally not a valid release
test: its newer `references/manifest.json` does not match the frozen v0.3.8
bridge. The CI historical lane checks out the frozen v0.3.9 commit before
running that reproducer.

## Next-version remediation contract

The 11 diagnostics may be cleared in a separate v0.4.3-or-later change only if
one atomic change also:

1. resolves the four B009 diagnostics without changing worker semantics;
2. regenerates the v0.3.8 bridge and any intentionally superseding release
   metadata rather than overwriting historical records;
3. regenerates and verifies the v0.4 source-to-direct provenance artifact;
4. reruns the Sage/container campaign and the full bounded regression suite;
5. only then changes the CI mypy job from advisory to blocking.

This boundary prevents a lint cleanup from silently changing a published
certificate or a paper's reproducibility claim.
