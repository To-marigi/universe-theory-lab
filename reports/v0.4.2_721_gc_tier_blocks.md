## Structural self-check, not a hardcoded count

Unlike the two predecessor gates, this module does not hardcode the
expected endpoint/pair counts per tier. It derives the expected pair count
from the star-graph structure directly: an endpoint with `k` paths must
contribute exactly `C(k,2)` same-endpoint pairs, so
`selected_pairs == selected_endpoints * k * (k-1) // 2` is checked before
any scalar expansion runs. A mismatch fails closed rather than silently
processing whatever pairs happen to be present.

## Safeguards and boundary

Each tier gate independently rejects duplicate path IDs, pair IDs, and
basis relation IDs, checks the global 407-path/1,529-pair inventory before
selecting blocks, and records the input native-IR digest and the
calibration-stage digest. Inverse tokens remain independent matrix
variables; no inverse saturation or elimination is run anywhere in this
sweep.

**All 1,529 same-endpoint GC pairs are now individually scalar-expanded and
internally consistent** (word identity iff scalar-zero matrix, at every
single pair). This is still not a commutativity proof: the fixed-vector GC
system as a whole has not been solved, inverse tokens are unsaturated, and
no Groebner/saturation/elimination step has run. What has changed is that
the GC coverage question — "does every same-endpoint pair difference reduce
correctly at the scalar level" — is now answered exhaustively rather than
by sampling.

No full 721 commutativity theorem, witness, or obstruction is issued.
