## 結論

全 `S` 上の `Lambda` localized row-module 証明書を発行する前提を、solverなしで
exact に棚卸しした。結果は、証明書契約は明確だが、単一の `D_14` pivotや一つの
pointwise minorだけでは source determinant localization 全体を覆えず、**finite minor
cover が必要**というものだった。955 の terminal、full-S obstruction、witness は
いずれも未到達である。

## exact manifest

- scalar ring: 246 coordinates
- scalar core: 4,152 entriesのうち非零1,814、相異なる非零生成元1,504
- upper-right fibre: `L` は 1,038×123、非Q列119、Q列4
- upper-right core は fibre に厳密線形（非線形 monomial 0）
- lower を消去した時点で、Q列だけに直接支持された core rowは0
- source determinant localizer: 131個、相異なるもの131、最大145項、最大次数5

source determinant の積は展開していない。したがって、ここでの131個は localization
factor の manifest であり、積を単元にした saturation 証明ではない。

## `D=0` の分離

対角ベクトル `u_i=(a_i,d_i)` の rank-2 部分は、次の3 open で分ける。

```text
D14 != 0
D14 = 0 and D12 != 0
D14 = D12 = 0 and D13 != 0
```

残り `D12=D13=D14=0` は rank-1 閉部分であり、別の監査が必要である。Gate17で
追加した `t=-13,s=2` の一点は `D14=0` だが `D12,D13` は非零であり、rank-2の
別アンカーで覆うべき点である。この preflight は rank-1 枝を解決していない。

## pointwise pivot の境界

既存の4点を再構成し、非Q列の exact pivot rank 111、pure-Q rank 3 を全点で確認した。
これは各点に 111×111 の候補 minor があることを示すだけで、係数環上の minor cover
や row-module membership を示さない。

必要な証明書の形は、scalar core ideal `I_S` と source determinant localizer `delta_e`
を用いて、各 anchor `D_1k` について概念的に

```text
(D_1k * product(delta_e))^N Lambda_1k
  = sum(row_coefficient * L_row) + sum(core_coefficient * scalar_core_generator)
```

を検証することである。今回の成果物ではこの恒等式を作っておらず、`certificate_issued=false`
とした。
