## bounded global subresult: pure lower family

`x=0` を固定した pure lower-triangular family

\[

\]

では、上記 lower system は単なる tangent approximation ではなく exact system である。
この形の行列積は同じ lower-triangular 形に閉じ、lower-left 成分は常に \(y\) の
\(\mathbb Q\)-linear form になる。reachable vector も

\[
v_c=(\alpha_c,L_c(y))^T
\]

と書け、\(L_c\) は exact linear form である。さらに

\[
D_c=\begin{pmatrix}0&0\\S_c(y)&m_c\end{pmatrix}
\]

なので reachable-MSR の非自明成分は

\[
\alpha_cS_c(y)+m_cL_c(y)=0
\]

となり、これも exact linear である。捨てた高次項は存在しない。

従って length-two CPOBC 712行と reachable-MSR 24行に対する既存の131-column
pivot certificate をそのまま exact に使用できる。選択行は CPOBC 108行と MSR
23行で rank 131、nullity 0 であるため、family 全体で唯一解は

\[

\]

である。従って全 operator は \(A_e=\operatorname{diag}(p_e,1)\)、特に
\(Q_1,\ldots,Q_4\) は diagonal で全6 commutators が零になる。strong GC の320 basis
relation、従って1,529 pair 全体もこの解で成立する。全165 determinants は \(p_e\ne0\)
である。また `p1-0` では

\[

なので reachable MSR を満たしながら \(N\ne0\) である。

この bounded subresult の verdict は
`V042_955_PURE_LOWER_TRIANGULAR_GLOBAL_NO_GO_PROVED` である。「global」はこの

## upper family 全体で同じ obstruction になる理由

upper-triangular background の積を lower 方向に微分したとき、lower-left 成分は
\(p\) と \(y\) のみに依存し \(x\) を含まない。reachable state と MSR residual の
lower 成分についても同じである。このため、上記131×131非零 minor は upper-family
parameter に依存しない定数である。

従って任意の exact upper solution で infinitesimal lower coordinate は (dy=0) で
ある。さらに \(y=0\) 自体が全 upper solutions に対する exact solution なので、
implicit-function/formal argument によりその点を通る局所 mixed branch も \(y=0\)
に一意である。既存 upper rank 証明はその17次元 family 上で全 Q commutator を零に
するので、局所枝でも Q は可換である。

この論理鎖は「全 mixed solution が \(y=0\)」を意味しない。非零 \(y\) の遠隔・孤立
branch には適用できず、一般 \(GL_2\) や unrestricted 572-scalar source system へも
昇格しない。
