## 1. 結論

既知の非特異対角CSG点における49次元のcore tangent kernelをexact `QQ` で二次まで
監査した。4,412 scalar core equationsを同時jet消去すると、Jacobian独立行427本に
対する従属行は3,985本であった。この3,985本が作る二次compatibility remainderは
**すべて恒等的に0**である。

したがって、全ての一次tangent vector `z` に対して少なくとも一つの二次係数 `w` があり、

```text
x(t) = x_CSG + t K z + t^2 w
```

はcore方程式を `O(t^3)` まで満たす。同じjet基底で6個のQ可換子・24 scalar entriesを
消去すると、全intrinsic quadratic formも0になった。従って任意のcore二次lift上で
Q可換子は二次まで消える。一次に続き、二次にも局所Q escapeはない。

これはCSG点での**局所・形式的・二次まで**の結果である。三次以上、形式解の収束、
remote component、unrestricted source-native 955全体のterminal obstructionは証明して
いない。full 955は `OPEN` のままである。

## 3. 二次compatibilityのstream消去

各core scalar polynomial `F` を基点とkernel上で二次まで展開し、

```text
J_F w + q_F(z) = 0
```

の組 `(J_F, q_F)` を同時にexact row eliminationした。ambient Hessian tensorは作らず、
各polynomialを一つずつ49変数の疎二次形式へ制限した。Jacobian部が0になった行の
二次部だけが、二次liftのcompatibility obstructionである。

| 非零compatibility forms | **0** |
| 零compatibility forms | 3,985 |
| compatibility span rank | **0** |

## 4. Q可換子の二次項

`Q1,...,Q4` の6可換子・24 scalar entriesを同じ同時jet基底へreduceした。

```text
basepoint failures                              0
first-order Jacobian remainders                 0
nonzero intrinsic quadratic forms              0 / 24
intrinsic quadratic span rank                   0
nonzero compatibility-span remainders          0 / 24
rank modulo core compatibility span             0
```

よって、coreの二次方程式を満たす全ての `(z,w)` に対して


である。これは二次までのQ escapeをblockするが、`O(t^3)` 以降の非可換性を否定しない。

## 5. terminal slack blind directions

前ゲートの16本のterminal slack blind coordinatesは49個のfree tangent coordinatesに
全て含まれる。raw core/Q restricted quadratic forms、core compatibility forms、Q intrinsic
formsの全てで、これらを含む二次monomial occurrenceは0であった。従って16方向はcoreと
Qに対して二次までsilentである。
これは自由なexact solution familyの証明ではなく、三次以降に初めて現れる可能性を残す。

## 7. 次ゲート

二次compatibility coneは49次元tangent space全体であり、Q二次項も全消去された。従って
generic solverへ移る根拠はまだない。三次では一次方向 `z` だけでなく、二次補正を
`w=w_particular(z)+K a` と書いたときの49個のfiber変数 `a` も保持しなければならない。
三次compatibilityの候補基底は49変数の `z^3` と49×49個の `z*a` からなり、上限は

```text
C(49+3-1, 3) + 49^2 = 20,825 + 2,401 = 23,226
```

である。full second-order jet fiber上の疎性・最大項数・メモリ上限をversioned preflightで
先に測る。安全なbudgetが立たない場合は `REACHABLE_VISIBILITY_OPEN_RESOURCE_LIMIT` 候補
として停止判断を記録する。
