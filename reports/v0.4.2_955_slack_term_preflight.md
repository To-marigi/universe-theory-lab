## 1. 結論

前ゲートで認証した476座標の unrestricted source-native slack chart を、初めて
exact scalar polynomial へ展開した。ただし保持したのは24 timid matrix と24 state
だけで、783 CPOBC と320 strong-GC は1 matrix blockずつ展開し、項数・digest・極値を
記録した直後に破棄した。full scalar manifest は作っていない。

主な実測値は次の通り。

| | CPOBC | strong GC | 合計 |
|---|---:|---:|---:|
| matrix blocks | 783 | 320 | 1,103 |
| scalar slots | 3,132 | 1,280 | 4,412 |
| 非零 scalar entries | 3,132 | 1,020 | 4,152 |
| 恒等的に0 | 0 | 260 | 260 |
| exact terms | 18,836 | 82,364 | **101,200** |
| 最大 terms / entry | 24 | 3,723 | **3,723** |
| exact 最大次数 | 4 | 9 | **9** |

構文的上限は前ゲートで CPOBC 5 / strong GC 11 だったが、実展開と相殺後は4 / 9。
入力は予想よりかなり疎で、完全保持を仮定した portable compact model は
3,376,080 bytes（約3.22 MiB）である。ただしこれは solver の中間基底増大を何も
予測しない。

## 2. 基底正規化と476座標

固定非零 preparation vector は `Omega=e1` に正規化した。一般 `GL_2` matrix chart
では任意の非零 `Omega` を一つの基底変換で `e1` へ送れ、全source matrixを同時共役
すれば CPOBC、strong GC、reachable-state MSR、非特異性、Q可換性は保たれる。

これは mixed ansatz の対角基底を仮定する操作ではない。座標は

```text
107 independent non-timid matrices * 4 entries = 428
24 reachable-MSR slack vectors * 2 entries     =  48
total                                            = 476
```

である。24 timid matrix は

```text
T_c = I - sum(non-timid A) + u_c (J v_c)^T
```

を非循環順に展開した。48 state entries は472 terms、96 timid matrix entries は
1,420 terms。実測最大次数はそれぞれ3と4で、構文上限7と8より低い。固定テストは
各sourceで展開後 residual を状態 `v_c` に再作用させ、48成分すべてが厳密に0に
なることを独立検査する。

## 3. 新規発見: 16 terminal slack blind directions

core relation に現れる座標は476中460だけだった。全域的に現れない16座標は、次の
8個の stage-4 source の slack vector 二成分である。

```text
p4-0000, p4-000e, p4-00cc, p4-00ce,
p4-0888, p4-088e, p4-08cc, p4-08ce
```

すなわち各 source について `u:c:0`, `u:c:1` の両方が、CPOBC と strong GC の
全4,412 scalar entry から恒等的に消える。これは特定点の Jacobian kernel ではなく、
展開多項式全体の support に基づく **global blind direction** である。

ただし、この16自由度だけで noncommutative Q witness が得られたとは言えない。
これらは terminal-stage timid matrix の slack で、標的 `Q1,...,Q4` は別の
gregarious source matrix から定義される。次ゲートでは、既知の対角 CSG 解を476座標へ
正確に持ち込み、blind direction を含む tangent kernel とQ可換子の一次変化を同時に
測る。
