# v0.4 weak `d=2` semantics classification

## Main result

Fixed-vector GC together with reachable-state MSR does **not** force
`Q_1,...,Q_4` to commute, even when:

- all 165 reduction/alias catalog records are identified on the 131 frozen
  transition orbits;
- all 783 strong CPOBC word identities are retained;
- both Eq. (113) source-index branches are retained as operator identities;
- all Eq. (139) instances in both source-domain readings are retained as
  operator identities; and
- every transition matrix is nonsingular over `QQ`.

The exact verdict is
`WEAK_D2_NONCOMMUTATIVE_WITNESS_CERTIFIED`.

## Rational witness

Let `omega=(1,0)^T`. For a transition from source stage `n`, let `w` be
the precursor cardinality and `m` the number of maximal precursor elements.
Set

`A_e = [[2^(w-m)/2^n, b_e],[0,1]]`,

where `b_e=4/2^n` for the gregarious transition and `b_e=0` otherwise.
The first column is the classical sequential-growth character with all
couplings equal to one. Hence every reachable state is a nonzero rational
multiple of `omega`.

For the antichain gregarious generators,

`Q_n = [[2^-n,4*2^-n],[0,1]]`.

Therefore, for `1<=i<j<=4`,

`[Q_i,Q_j] = [[0,4(2^-i-2^-j)],[0,0]] != 0`.

In particular `[Q_1,Q_2]=[[0,1],[0,0]]`. Every transition determinant is
`2^(w-m)/2^n`, and `det(Q_n)=2^-n`, so no inverse is formal or singular.

## Minimal recovery conditions

For an MSR residual `R_c`, equality on tested states implies the operator
identity exactly when evaluation is injective on the declared residual
space. A simple dimension-two sufficient condition is that the reachable
test states at each source span `K^2`; two independent vectors then force
`R_c=0`.

The same condition applies to each GC path residual `D=P_alpha-P_beta`.
Testing on a basis of `K^2` forces `D=0`. One vector cannot separate the
full algebra `End(K^2)`, although it can be separating for a smaller
project-specific residual subspace. Once both residual families lift to
strong operator identities and the frozen occurrence identification is ON,
the existing finite strong-profile commutativity theorems apply.

This witness proves that some semantic strengthening is necessary. It does
not decide whether strong GC alone or strong MSR alone is sufficient for
occurrence identification ON. Both one-sided profiles remain open after the
v0.4.1 scope audit. Relation-ID minimality also remains open and is not
inferred from the triangular scouts.

The v0.4 machine artifact predates the 406-occurrence audit. Its sentence that
an ON assignment is automatically an OFF witness is only a conditional
orbit-constant transfer argument, not a direct certificate for the naturally
labelled 406-occurrence system. No OFF theorem should be cited until the
labelled CPOBC/MSR/Eq. (113)/Eq. (139) lifts have been compiled and checked.

## Scope

No saturation or unit-ideal calculation was run because the prescribed
counterexample-first gate succeeded. The result is finite (`n<=4`),
nonsingular, rational, and `d=2`. It makes no `n=5`, `d=3`, restriction,
lifting, or infinite-CPOBC claim.

The v0.4 tests plus the directly dependent CPOBC/GC/Eq. (112) suites pass
42/42. A broader `tests/final_theory` run passed 279 tests; its remaining

raw-byte and release-manifest checks. Those checks correctly reject the
intentional v0.4 changes to `.gitignore`, `references/sources.json`, and
`references/manifest.json`. The published v0.3.9 release remains
reproducible at its pinned commit; a new v0.4 release bridge is outside this
research-result scope.
