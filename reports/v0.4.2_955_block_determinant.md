## 0. 前ゲートが残した問い

[unit pivot matching](v0.4.2_955_unit_pivot_matching.md) は、必要な111本の非Q
ピボット列すべてが source-localizer 単元係数を持ち、単元辺の最大マッチングが
ちょうどランク111を異なる行の上で達成することを示した。しかし
**単元エントリのマッチングは単元行列式を意味しない**——行列式は置換にわたる
符号付き和だからである。本ゲートはその問いに決着をつける。答えは**否**である。

## 1. Dulmage–Mendelsohn 分解

マッチした列の上に有向グラフを張り（列 `c` → 列 `c'` を「`c` にマッチした行が
`c'` に台を持つ」で定義）、強連結成分を取る。

| | |
|---|---|
| 成分数 | **60** |
| 単元成分（サイズ1） | 39 |
| 非自明成分 | 21 |
| 最大ブロック | **15**（次いで 7、あとは3以下） |

**このブロック構造はマッチングの取り方に依存しない**（マッチした有向グラフの
SCC は二部グラフの台に対して標準的）。したがって15は本質的な限界であり、
別のマッチングでブロックを小さくすることはできない。

行列式はブロック行列式の積なので、39個の単元成分は単元因子を寄与し、
問いは非自明21ブロックに帰着する。

## 2. サイズ3以下の19ブロック：**どれも単元ではない**

21ブロックのうちサイズ3以下の19個の行列式を厳密に計算した。

**19個すべてが非単元。** 前ゲートの三角性ヒューリスティクスが示唆した
「あと13ステップ」は、実際には三角化が最初の一手から成立しないこと
（どの行も単独列を持たない）を反映していた。

### 現れた新しい非単元因子（10個）

```
v52 - v55
v271 - v283
v199*v71 - v367*v79
v123*v159 - v355*v387
v251*v3 - v271*v403
-v111*v383 + v143*v7

-v172*v315 - v175*v424 + v315

-v172*v91  - v175*v52  + v91
```

**いずれも source 行列の対角成分ではない。** したがって131個の source
determinant で局所化しても可逆にならない。この行選択では消去がその局所化環上で
有効にならない。

サイズ7と15のブロックは行列式を評価していない。小ブロックで既に否定的結論が
確定しており、大ブロックを評価しても結論は変わらないためである
（`determinant_evaluated: false` と理由を記録）。

## 3. ルートは論理的に死んではいないが、探索空間が爆発している

各ブロック列は複数の単元行を持つので、**別のマッチングなら単元ブロック行列式に
なる可能性は残る**。しかしその探索空間は：

| | |
|---|---|
| 全列が代替単元行を持つ | ✔ |
| 1列あたり最大の単元行数 | 194 |
| **サイズ15ブロック単独の代替マッチング数** | 約 **1.4 × 10²⁹** |
| 非自明ブロック全体 | 約 3.4 × 10¹⁰² |

そして**単元選択が存在すべき構造的理由は何も現れていない。**
