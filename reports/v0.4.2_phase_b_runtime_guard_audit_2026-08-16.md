# Phase-B runtime guard audit — 2026-08-16

Status: **`PHASE_B_RUNTIME_GUARD_AUDIT_COMPLETE_NON_EVIDENTIARY`**

## Finding

The integer-ticket draw path computed `256**byte_count` before checking the
portable counter-stream byte cap.  A malformed or unexpectedly large exact
ticket total could therefore allocate a large intermediate integer before the
intended fail-closed `CounterRngLimit` was raised.

The guard now rejects an oversized ticket byte count before constructing the
range size.  The change is operational only: it does not alter any accepted
ticket, weight, trajectory, observable, or scientific verdict.
