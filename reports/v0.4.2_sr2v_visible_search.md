## 3. Exact invariant-line-breaking tangent obstruction

The stronger bounded result concerns every valid upper-triangular base point
with the frozen diagonal characters

```text
A_e(0) = [[p_e,x_e],[0,1]],   Omega=e_1.
```

Allow all four entries of all 131 ON transition matrices, together with the
external `Q_5`, to vary over dual numbers.  This gives 528 first-order
coordinates.  At the frozen noncommutative witness, the complete Jacobian has

```text
rank     455
nullity   73
```

but none of those 73 tangent directions contains a lower-left coordinate of
an actual `n<=4` transition.  The only lower-left kernel coordinate is the
out-of-cutoff `Q_5_EXTERNAL:10` direction.

The reason can be separated from the other 397 tangent coordinates.  At an
upper-triangular base, the lower-left derivative of a product uses only the
two diagonal entries and lower-left derivatives:

```text
d(AB)_21 = dA_21 B_11 + A_22 dB_21.
```

Likewise, for `A=[[p,x],[0,1]]`,

```text
d(A^-1)_21 = -dA_21/p.
```

Neither formula contains the base upper-right value `x`.  Consequently the
lower component of CPOBC, Eq. (113), Eq. (139), fixed-vector GC, and
reachable-state MSR forms one base-`x`-independent 1,187-row system.  Its
exact rank on 132 lower coordinates is 131 and its kernel is precisely

```text
span{Q_5_EXTERNAL}.
```

The normalized row digest is
`dc8f354ac3726532365d48144024fcc1ca53d84957c777f190350d4f45a4ea9c`.
The implementation obtains the same digest from pure-lower differentiation,
full-matrix differentiation at the noncommutative witness, and a zero-upper
control point.  All 407 first-order reachable lower components and all
`6 x 407 x 2 = 4,884` commutator-action components reduce to zero modulo the
Jacobian rows.

## 4. Discarded construction and numerical scouts

An endpoint-frame construction

```text
A_(c->d) = p_(c->d) S_d S_c^-1
```

was checked as a design probe.  It makes all 1,529 GC path pairs agree as
operators, permits exact sourcewise harmonic vectors satisfying all 24
reachable-state MSR equations, and readily gives reachable rank two with
visible noncommuting `Q` matrices.  It is not a CPOBC witness: the tested
nonconstant frame choice fails all 783 raw CPOBC equations, both Eq. (113)
branches at three records each, and every completed Eq. (139) instance.  The
construction is therefore rejected, but it isolates CPOBC—not GC or
statewise MSR—as the barrier for this otherwise natural cocycle mechanism.

A mixed nonlinear least-squares scout with commutator and reachable-rank
saturation reduced its residual but produced no exact or rationally
certifiable point.  It is not retained as evidence and does not affect any
verdict.

## 5. Consequence for the next search

Repeating generic local perturbations inside the certified principal opens is
now low value.  The next exact search must target the explicit remaining
regions:

1. the aligned degeneracy hypersurface `Delta_align=0`;
2. the exceptional transverse splitting locus `Delta(r,s)=0` and then the

4. the state-native 131-variable shear and structured-`beta` charts; or
5. the pair-irreducible and triple-irreducible commutator-pivot branches.

The first item in branch 5 is now compiled: on the frozen state-native shear
slice, `D12=det[Q_1,Q_2]` is a nonzero seven-term cubic and all relation
ledgers have an exact 29,994-term sparse manifest.  This proves only that the
ambient `D12!=0` open is nonempty; whether the relation variety meets it is
still unresolved and no solver has run.

The six nonzero-Q-commutator pivots now give a complete four-way structural
cover, so a single commutator-determinant patch is no longer treated as the
whole irreducible locus.

Any candidate must still pass direct exact substitution into all 783 CPOBC
relations, 712 inverse rewrites, both Eq. (113) branches, both Eq. (139)
domains, all 1,529 fixed-vector GC pairs, all 24 source-matched reachable-MSR
constraints, and every nonsingularity predicate.
