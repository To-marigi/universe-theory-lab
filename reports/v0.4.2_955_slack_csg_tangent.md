## 1. 結論

既知の非特異対角 CSG 解を476座標 unrestricted slack chart へ厳密に逆写像し、
CPOBC + strong GC の全core Jacobianと、6個のsource-defined Q可換子の微分を比較した。

```text
core Jacobian rank                    427
CSG点のZariski tangent dimension       49
Q commutator gradient raw rank          6
Q rowsをcoreへ追加したrank増分           0
```

従って、CSG点における **全てのcore tangent directionでQ可換子の一次変化は0**。
前ゲートで見つけた16本のterminal slack blind directionも、coreだけでなくQ可換子に
対して一次的にsilentである。

これは first-order obstruction であって、CSG点近傍の非可換解を否定する定理ではない。
曲線に沿って可換子が `O(t^2)` で立ち上がる可能性は残る。full 955は `OPEN`。

## 2. 対角CSG点のslack逆写像

全131 source matrixを

```text
A_e = diag(p_e, 1),  p_e = CSG(t_j=1)
```

に固定する。107 independent matrixの座標は直接決まる。各 timid source では
reachable stateが `(a_c,0)`、`a_c!=0` なので、

```text
T_c = I - sum(non-timid A) + u_c (Jv_c)^T
```

のtarget対角成分から `u_c` が一意に決まる。24 source全てで

```text
u:c:0 = 0,
u:c:1 != 0.
```

と出た。したがって非零slack座標は24個。特に `u:p1-0=(0,1)` で、既存の
`N!=0` triangular scout の `D_p1=diag(0,1)` と一致する。

再構成した全131行列はtargetとexact一致。determinantは

| 値 | orbit数 |
|---|---:|
| `1/16` | 56 |
| `1/8` | 40 |
| `1/4` | 25 |
| `1/2` | 10 |

で全て非零。よって基点はnonsingularかつ `N!=0` open上にある。open条件はこの点の
tangent spaceへ追加の線形式を課さない。

## 4. Q可換子の一次 obstruction

`Q1,...,Q4` は各stageのgregarious source matrixへ直接束縛した。対角CSG点では全て
対角なので6可換子・24 scalar entriesは0。微分すると12 rowが非零、raw rank 6。

この12 rowをcore Jacobianのexact QQ echelonへ一つずつreduceすると、

```text
nonzero remainders = 0
rank(core + d[Qi,Qj]) - rank(core) = 0.
```

従って各Q可換子微分はcore Jacobianのrow spanに含まれる。線形代数的に同値な表現では、
全 `delta` satisfying `J_core*delta=0` に対して

```text
d[Qi,Qj](delta)=0  for every 1<=i<j<=4.
```

固定テストは成果物のrank値だけでなく、3,890 raw core rowsを再構成し、12 Q rowsを
echelonへ再reduceして全remainderが空になることを独立検査する。

## 7. 次ゲート

