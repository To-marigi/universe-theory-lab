## Finding

The v0.3.8 line-ending bridge contains a historical raw-byte target for
`references/manifest.json`. That file is a living literature/citation-gate
ledger and grew after the v0.3.8 freeze, so its current bytes cannot satisfy
the frozen target hash.

The frozen bridge JSON remains byte-for-byte unchanged. Its historical target
and binding are retained explicitly by the bridge builder, while current
verification and `LegacyRawDigestResolver` exclude the living path from
current legacy-byte resolution. The consumer JSON Pointer is still checked.
