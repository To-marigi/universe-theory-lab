## 1. Three non-aligned charts

Write

```text
b_i       = lower diagonal Q_i coordinate (a unit),
r_i       = a_i/b_i,
delta_i   = b_i*(r_i-1),
g_k       = r_k-r_1,                 k=2,3,4,
x_i       = b_i*z_i,
v_i       = b_i/b_1.
```

The three source-native Eq. (120) rows are

```text
E_ij = g_i*(z_j-z_1)-g_j*(z_i-z_1),   2 <= i < j <= 4.
```

On `U_k=D(g_k)`, every solution of these rows has the unique form

```text
x_(1..4) = delta*h + v*w,
Q5       = q5,
h        = (z_k-z_1)/g_k,
w        = b_1*(z_1-(r_1-1)*h).
```

The certificate checks both directions.  Substitution makes all three
`E_ij` zero.  Conversely, after multiplication by `g_k`, each reconstruction
residual is exactly the relevant Eq. (120) numerator.

For upper-triangular matrices,

```text
c_ij = [Q_i,Q_j]_(12) = delta_i*x_j-delta_j*x_i.
```

On the displayed kernel,

```text
c_ij = (b_i*b_j/b_1)*(r_i-r_j)*w,
c_1k = -b_k*g_k*w.
```

Thus `b_k` and `g_k` are units on `U_k`, and the single target `c_1k`
vanishes exactly when the remaining noncommutative coordinate `w` vanishes.

## 2. Exact repair condition, including Q5

Let `rho=(rho1,...,rho5)` be any row of the five-column common-core Schur
matrix.  Its restriction to the Eq. (120) kernel is

```text
A_r*h + B_r*w + C_r*q5,
A_r = rho . delta,
B_r = rho . (b/b_1),
C_r = rho5.
```

Let `T_k` be the matrix of all triples `(A_r,B_r,C_r)` over

```text
S_k = R[g_k^-1],
```

where all declared base units have already been inverted.  The exact
necessary-and-sufficient obligation on `U_k` is

```text
e_w=(0,1,0) belongs to Row_(S_k)(T_k).
```

Equivalently, every Schur-kernel vector `(h,w,q5)` must have `w=0`.  Valid
certificate forms include:

1. a direct localized row identity for `e_w`;
2. two rows with `C_r=C_s=0` and localized-unit minor
   `D_rs=A_r*B_s-A_s*B_r`, using
   `A_r*ell_s-A_s*ell_r=D_rs*w`;
3. a localized-unit three-by-three minor in columns `(A,B,C)`;
4. several local identities together with an exact Bezout or saturation
   certificate proving their opens cover `U_k`.

The `C=0` premise in item 2 is essential.  The exact rows

```text
(A,B,C)=(1,0,1), (0,1,1)
```

have unit `AB` minor, but their kernel is generated by `(-1,-1,1)`, whose
`w` coordinate is nonzero.  Their rank rises from two to three after adjoining
`e_w`.  Therefore a proof that silently drops `Q5` is unsound.

Changing the visible-vector reference does not create another repair chart.
With reference `Q_k`, write

```text
x = delta*h + (b/b_k)*w_k,       w_k=(b_k/b_1)*w_1.
```

The coefficient `A` is unchanged, while

```text
B^(k)=(b_1/b_k)*B^(1),
D_rs^(k)=(b_1/b_k)*D_rs^(1).
```

The certificate verifies these identities for all four references.  Since
`b_1/b_k` is a declared unit, relabeling through `Q2`, `Q3`, or `Q4` cannot
remove a nonunit factor or produce a genuinely new minor.

## 3. Aligned remainder

On

```text
L = V(g2,g3,g4) intersect D(f),   f=r_1-1,
```

Eq. (120) vanishes identically and `delta=f*b`.  Parametrize

```text
x_1 = b_1*h,
x_2 = b_2*(h+w2),
x_3 = b_3*(h+w3),
x_4 = b_4*(h+w4),
Q5  = q5.
```

Then

```text
c_1i = f*b_1*b_i*w_i,   i=2,3,4.
```

Hence this locus has three independent obstruction coordinates, not the
single `w` of a non-aligned chart.  A Schur row restricts to

```text
A*h+B2*w2+B3*w3+B4*w4+C*q5.
```

Over `S_L=(R/(g2,g3,g4))[f^-1]`, the exact obligation is that all three
coordinate rows `e_w2,e_w3,e_w4` belong to the aligned Schur row module.  A
three-by-three `(B2,B3,B4)` minor is sufficient only when the selected rows
have `A=C=0`.  Otherwise one needs a genuine five-column module identity, a
localized-unit five-by-five minor, or a certified local cover.

The remaining locus `V(g2,g3,g4,f)` has `r1=r2=r3=r4=1`, hence
`delta_Q=0`; all six commutator rows vanish identically and no repair is
needed.
