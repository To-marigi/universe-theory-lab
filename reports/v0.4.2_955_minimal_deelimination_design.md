## 局所補題

source `c` の MSR residual を

\[
D_c=\sum_tA_t-I
\]

とする。strong GC では source state `v_c` は path に依らず、初期ベクトルが
非零で各遷移が可逆なら `v_c\ne0` である。timid operator を

\[
T_c=I-\sum_{t\;\mathrm{non\text{-}timid}}A_t+N_c,
\qquad
N_c=u_c(Jv_c)^T,
\quad J=\begin{pmatrix}0&-1\\1&0\end{pmatrix}
\]

と置くと `D_c=N_c` であり、`N_cv_c=0` である。逆に `Nv=0` かつ
`v\ne0` なら N の各 row は一次元 annihilator
`span((Jv)^T)` に属するため、一意な `u\in K^2` が存在する。従ってこれは
reachable-state MSR を満たす 2-by-2 slack 全体を尽くす。

24 source の各々に `u_c` の二成分を導入するので +48 scalar である。全ての
`u_c=0` は old strong-MSR slice `N_c=0` に正確に戻る。

## なぜ「+48だけで既存Q campaignを再利用」は不可か

凍結 v0.3.2 の non-timid 117 occurrence は Eq.(107) に現れる下位
`T_precursor` を Eq.(108) で展開する。Eq.(108) は dependency graph で
`MSR_ELIMINATION` と明記されている。したがって slack `T` に置換すると
再帰的 source-level re-expansion が必要である。

さらに Eq.(112) compiler の B factors は v0.3.2 Eq.(107)/(108) reduction を
展開しており、forward certificate 自身が Eqs.(107),(108),(111),(112) に依存する。
よって existing Q reconstruction、42 QQ証明書、及びそれらの transition
predicates は弱MSR profileへ流用できない。

## Eq.(120) と chart cover

four invertible source antichain matrices が、source-native に定義され、かつ
CPOBC+strong GC の下で Eq.(120) を満たすことが独立に証明されれば、R2--R4 の
S1/S2/S3 **代数的分割そのもの**は再利用できる。これは MSR を使わない線型代数で
ある。一方、既存 chart solver は strong-MSR Q reconstruction 由来の B と
transition predicates を含むため再利用不可である。

現在は source-native Eq.(120) provenance certificate が無い。従って chart cover
は `CONDITIONALLY_REUSABLE_ONLY` とし、これを solver 実行の前提条件にする。

2. Eq.(108) 展開を用いない strong-GC な Eq.(112) 型 conjugation、または source

elimination variable count や proof complexity の上界ではない。
