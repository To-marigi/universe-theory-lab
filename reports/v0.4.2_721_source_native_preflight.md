## Bug controls

The first implementation attempt omitted adjacent free-group cancellation and
incorrectly made all 783 CPOBC equations appear nonzero.  The compiler now
applies the same exact reduction rule as the predecessor implementation, and a
regression test covers (G G^{-1}=1).  A JSON round-trip test also caught and
fixed integer-versus-string distribution keys.

Expanding all 1,529 path pairs immediately into generic 2-by-2 scalar
polynomials exceeded the 120-second execution budget.  That expansion is
therefore not silently treated as a result: this gate stores the exact
free-reduced word IR and marks scalar expansion as a separate bounded gate.
