## 1. 結論

前段で保留した rank 3 の1次消去、954本のCPOBC双線形形式の解析、165 occurrence
の非特異条件の持ち込みを、厳密な `QQ` 線形代数だけで完了した。

宣言済み mixed ansatz

```text
A_e = [[p_e, x_[e]], [y_[e], 1]],  p_e = CSG(t_j=1)
```

の中では、955 profile (`CPOBC + strong_GC + reachable_state_MSR`) の解集合は
**17次元の pure-upper 線形族だけ**である。したがって

- `x != 0, y != 0` の remote / disconnected mixed component は存在しない。
- 全ての解で `Q1,...,Q4` は可換。
- 非可換 witness はこの mixed ansatz 内には存在しない。
- 165個の source nonsingularity occurrence は全て自動的に満たされる。

これは **mixed ansatz 限定の終端**である。一般 `GL_2` や無制限の
source-native slack 系については何も決めておらず、full 955 search は open のまま。

## 4. 二枝の厳密解析

体上なので `s21=0` と `s21!=0` に分ければ尽くされる。

### 4.1 `s21 != 0`

CPOBCから

```text
t11 = t15 = t16 = t18 = t22 = 0
```

が従う。この代入後、残るのは strong GC 47式と reachable-state MSR 16式の
合計63本で、全て斉次1次式。結合rankは21で、RREFは残りの全ての`t`を0にし、

```text
s11 = 5/4*s22
s15 = s22
s16 = s22
s18 = 7/6*s22
s21 = 1/12*s22
```

を与える。自由変数は、次の16座標と `s22` の合計17個。

```text
s0,s1,s2,s3,s4,s5,s6,s7,s8,s9,s10,s12,s13,s14,s17,s20,s22
```

この線形パラメータ表示へ代入すると残余式は0本になる。

整数方向で書けば `u=s21` として

```text
(s11,s15,s16,s18,s21,s22) = (15,12,12,14,1,12)*u.
```

### 4.2 `s21 = 0`

CPOBCは全て消える。strong GC 94本の単項式と reachable-state MSR の21本の
1次式の結合rankは26で、全`t`と

```text
s11=s15=s16=s18=s22=0
```

を強制する。残る5本の2次MSR式もこの代入で恒等的に消える。自由変数は上の
16座標であり、この枝は17次元族の `s22=0` 超平面に一致する。

したがって二枝の和は単一の17次元線形族である。成果物は一般17パラメータ点で
縮約系の **1,933成分を全検査し、失敗0** を記録する。

## 6. 新規発見の意味

前段の `Q` 可換子24成分・60項が「恒等的に0ではない」という記録は、46変数の
未消去座標上での記録として正しい。しかし、その系自身が含む rank 3 の1次式を
法とすると、可換子は全て0になる。したがって heavy solver を投入する理由は
この ansatz では消滅した。

また、最終17次元という値は先行 tangent scout の upper nullity 17 と一致する。
本ゲートは、その局所的に見えていた上三角方向が実は mixed ansatz の**大域的な
全解集合**であることを示す。
