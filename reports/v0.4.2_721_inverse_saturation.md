# v0.4.2 721 inverse-token saturation

Status: **`V042_721_ALL_EIGHT_INVERSE_TOKENS_SATURATE_EXACTLY_GENERIC_2X2_MATRIX_IDENTITY_OPEN`**

Every prior 721 gate flagged the same limitation: the 8 inverse tokens used
by the native IR (`G_p2-2^-1`, `G_p3-002^-1`, `G_p3-006^-1`, `G_p3-024^-1`,
`G_p3-026^-1`, `Q_1^-1`, `Q_2^-1`, `Q_3^-1`) were compiled as scalar-free
matrix variables with no algebraic tie to their forward generators' matrix
entries — the "64 inverse-relation matrix-entry slots" identified as far
back as the [preflight gate](v0.4.2_721_source_native_preflight.md). This
gate closes that gap.

## What was done

For a generic invertible 2x2 matrix `A = [[a,b],[c,d]]`, the closed-form
inverse is `A^-1 = (1/det A) * [[d,-b],[-c,a]]`. For each of the 8 tokens:

- one fresh scalar variable `D_<token>`, standing for `1/det(A)`;
- the defining relation `D_<token> * det(A) - 1 = 0` (this is a new
  constraint the token must satisfy, not a claim that is itself asserted
  zero);
- the inverse matrix built directly from `a,b,c,d` and `D_<token>`, replacing
  the previously-free `M_<token>_INV_ij` variables.

With the inverse built this way, `A * A^-1 - I` and `A^-1 * A - I` were
computed exactly (integer-coefficient multivariate polynomials, the same
representation used by every earlier 721 gate) and checked entry by entry:

- **off-diagonal entries are the exact zero polynomial** — pure cancellation,
  no relation needed;
- **diagonal entries equal `D_<token> * det(A)` exactly**, term for term, as
  a raw polynomial (not merely numerically or up to some other combination)
  — so applying the defining relation reduces them to `1`, closing the
  two-sided inverse identity.

All 8 tokens x 8 checked entries (4 entries x 2 orderings, `A*A^-1` and
`A^-1*A`) = **64 slots, all satisfied**.

## What this is and is not

This is standard linear algebra carried out exactly and mechanically, not a
search: a generic invertible 2x2 matrix always has this closed-form inverse,
and the gate's only job was to verify the native IR's specific tokens
instantiate it correctly, term for term, with no shortcuts. It is a genuine
first for the 721 track in the sense that it is the first gate to give the
inverse tokens *any* algebraic content at all.

It is **not** a substitution into the previously compiled CPOBC (783
equations), strong MSR (24 equations), or GC (1,529 pairs) scalar residuals.
Those were all compiled treating inverse tokens as free variables; none of
them have been re-checked under the `D_<token> * det(A) = 1` relations. That
re-substitution — and whether any previously-nonzero residual becomes zero,
or whether new obstructions appear — is left to a successor gate.

## Safeguards and boundary

The gate cross-checks its inverse-token list and slot count (8 tokens, 64
slots) against the source-native preflight gate's own count before running,
so a change in the compiled generator inventory fails closed rather than
silently checking a different set of tokens.

No full 721 commutativity theorem, witness, or obstruction is issued.
