## 1. 出発点：二重次数の実測

トーラス次数証明書は各成分 `(i,j)` が `deg_x - deg_y = j-i` で均一であることを
示していた。より細かい**二重次数** `(deg_x, deg_y)` を凍結済み manifest 上で
実測すると、CPOBC ブロックについて次が得られる。

| CPOBC 成分 | 現れる二重次数 | 項数 |
|---|---|---|
| `00` | `(1,1)` のみ | 1,642 |
| `01`（右上） | `(1,0)` のみ | 2,831 |
| `10`（左下） | `(0,1)` のみ | 2,831 |
| `11` | `(1,1)` のみ | 1,642 |

すなわち **CPOBC の非対角ブロックは mixed ansatz 全体で厳密に線形**である。
右上は `x` の定数係数線形形式で `y` を含まず、左下は `y` の定数係数線形形式で
`x` を含まない。対角は厳密に双線形。

これは基点まわりの線形化ではなく、恒等式である。

## 5. 副産物：1次部分は rank 3

縮約系のうち、既に斉次1次形式になっている成分が 5 本ある。その厳密ランクは
**3** で、変数は `s19, s21, t19, t21` の 4 個だけに集中している。

```
strong_GC 01          :  2*s19 - 6*s21 = 0
strong_GC 10          : -1/2*t19 + 6*t21 = 0
reachable_MSR_vector 1:  t19 + 4*t21 = 0
reachable_MSR_vector 1:  7/2*t19 + 6*t21 = 0
reachable_MSR_vector 1:  1/2*t19 + 26*t21 = 0
```

`t` 側の 4 本は 2 変数に対して rank 2（例えば第1・第2式の行列式は `-8`）なので
`t19 = t21 = 0` を強制し、`s` 側は `s19 = 3*s21` を与える。残りパラメータの上界は
**43** になる。

本ゲートではこの消去は**実行していない**（`eliminated_here: false`）。測定として
記録するにとどめる。
