## 0. 発端

[可換子 span ゲート](v0.4.2_955_commutator_span.md)と
[第二対角 span ゲート](v0.4.2_955_second_diagonal_span.md)は、6組の可換子形式を
サンプル点ごとに個別の row-span 判定で検証していた。upper stratum 上で `L` の
119個の非Q列を消去し「Q列4本だけに支持された関係式」を抽出したところ、**独立な
関係式がちょうど3本**（4次元中 codim 1）現れ、しかも6組の可換子形式が**全て
同じ3本の基底に厳密分解**されることが2つの異なる点で確認された。この構造は
偶然ではなく、**プロジェクトが既に証明済みの source-native Eq120**
（`results/v0.4.2_eq120_source_provenance.json`、SR3b-A で使用）と同一の機構
であることが判明した。

## 1. Eq120 のスター恒等式

`1=k<m<n<=4` に対し、Eq120 は次を与える（既に証明済み、本ゲートは前提として
参照するのみ）:

```
Q_n Q_1^{-1} Q_m = Q_m Q_1^{-1} Q_n
```

upper stratum 上で `Q_i = [[a_i,b_i],[0,d_i]]`（上三角）として、この恒等式の
`(0,1)` 成分を展開すると、**厳密に3×3行列式**に一致することを記号的に検証した:

```
E_mn = det [[a_1,d_1,b_1],[a_m,d_m,b_m],[a_n,d_n,b_n]]
```

（`_eq120_star_entry` の出力と `sympy.Matrix(...).det()` の差が恒等的に0である
ことをテストで確認。）

## 2. 3本のうち独立なのは2本

`E_23=E_24=E_34=0`（`m,n∈{2,3,4}`）は見かけ上3本の関係式だが、`E_23,E_24` を
`b_2,b_3` について解くと（`a_1 d_4 - a_4 d_1 != 0` のもとで一意に解ける）：

```
b_2 = (a_1 b_4 d_2 + a_2 b_1 d_4 - a_2 b_4 d_1 - a_4 b_1 d_2) / (a_1 d_4 - a_4 d_1)
b_3 = (a_1 b_4 d_3 + a_3 b_1 d_4 - a_3 b_4 d_1 - a_4 b_1 d_3) / (a_1 d_4 - a_4 d_1)
```

この代入のもとで **`E_34` は恒等的に0になる**（仮定ではなく、代入後に
`sympy.simplify` で0と確認した多項式的帰結）。すなわち独立な関係式は2本のみ。

## 3. 中心の補題：6組すべてが1個のスカラーに比例する

上記の代入のもとで、6組の可換子 `(0,1)` 成分をすべて計算すると、**全てが
`Λ := c_14 = (a_1-d_1)b_4 - (a_4-d_4)b_1` の厳密なスカラー倍**になる:

| 対 `(i,j)` | 係数 × `(a_1 d_4 - a_4 d_1)` |
|---|---|
| (1,2) | `a_1 d_2 - a_2 d_1` |
| (1,3) | `a_1 d_3 - a_3 d_1` |
| (1,4) | `a_1 d_4 - a_4 d_1`（＝1） |
| (2,3) | `a_2 d_3 - a_3 d_2` |
| (2,4) | `a_2 d_4 - a_4 d_2` |
| (3,4) | `a_3 d_4 - a_4 d_3` |

**係数はすべて `a,d` だけの厳密な 2×2 小行列式**であり、`b` を一切含まない。
`c_ij - (係数) · Λ` が恒等的に0であることを `sympy` で検証し（残差チェック）、
係数×分母が多項式であることも確認した。

### 帰結

> **Eq120 のスターが成り立ち `a_1 d_4 - a_4 d_1 != 0` である局所では、
> `Q_1,...,Q_4` の全可換性は、6本の独立な row-span 判定ではなく、
> `Λ = 0` という単一のスカラー条件に完全に同値である。**

## 6. 主張境界

- これは代数的恒等式であり、`Λ` が `S` 上で恒等的に0であることの証明ではない。
- 恒等式には `a_1 d_4 - a_4 d_1 != 0` が必要。この条件が破れる点は別のアンカー
  （例えば `k=1,n=4` 以外の組、あるいは `k=2` のスター）が必要で、本ゲートは
  カバーしていない。
- upper stratum は無制限 955 profile ではなく、mixed 点については何も言えない。
- 本補題単独では witness も一般 obstruction も認証しない。
- 全体判定 `FINAL_THEORY_OPEN` は不変。

## 7. 次のゲート（再定義）

6本の row-span 判定は不要になった。残る問いはただ一つ：

> **`Λ = c_14` は core によって0に強制されるか、それとも `a_1 d_4 - a_4 d_1 != 0`
> を満たす `S` 上のどこかの厳密な点で `Λ != 0` となるか。**

前者なら obstruction 側の証拠が一段と強くなる（6組ではなく1組の理由が分かった
上での0）。後者ならその点は **955 witness 候補**であり、非特異性・`N != 0`・
Eq113/Eq139・reachable visibility を別途満たす必要がある。
